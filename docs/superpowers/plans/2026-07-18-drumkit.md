# Physical-Modeling Drumkit Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Seven-voice physical-modeling drumkit as `patches/lib/kit/*.sub` subpatches, enabled by an optional `ratios:` config on `modal`.

**Architecture:** One small C++ change — `modal` grows a `ratios:` config (explicit mode placement, `structure` reinterpreted as a warp) validated at graph-compile time via a new optional `ModuleInfo::validate` hook. Everything else is patch text: six `.sub` voice files sharing a trig/accent/tune/decay contract, plus a demo groove patch.

**Tech Stack:** C++20, doctest, CMake/ctest via mise tasks, ratsnest patch DSL.

**Spec:** `docs/superpowers/specs/2026-07-18-drumkit-design.md` (authoritative for semantics).

## Global Constraints

- `Module::process()` never allocates, locks, or does I/O (design rule 3). `ratios_` is sized in `init()` only.
- Errors never kill the session: bad configs are graph-compile errors with line:col (rule 6). `init()` only ever sees validated configs.
- Patch identifiers are lowercase only (uppercase breaks note lexing); config strings are always quoted.
- Kit voices gain-stage to peak ≈ ±0.8 at full accent (≈ 0.68 at the 0.7 default — the accent VCA gain is `0.5 + 0.5·accent`).
- Docs are part of the diff: `docs/modules.md` / attribution / spec pointers land in the same commit as the behavior they describe.
- Build/test: `mise run build`, `mise run test`, `mise run test-san` (ASan+UBSan) must pass at every commit. CI gate: `mise run ci`.
- Renders are 32-bit-float WAV (`write_wav_f32`); the check scripts below parse that format.
- `<scratchpad>` below means this session's scratchpad directory (the harness lists it in the system prompt as "Scratchpad Directory"); substitute the literal path everywhere it appears, including inside heredocs. Scripts there are working aids, never committed.
- Subpatch input defaults are read only when NO outside cable feeds the port — cabling a modulator into `accent` replaces the 0.7 default, so patches must cable the base too (`0.7 -> voice.accent` plus the modulator; cables sum).
- Commit prefixes: feat/fix/test/docs. No AI attribution.

std::string validate_cfg(const Config& cfg) {
  if (!has_cfg(cfg, "ratios")) return {};
  if (has_cfg(cfg, "modes"))

  if (r.size() > 128) return "'ratios:' accepts at most 128 entries";

  return {};
}

  void init(double rate, const Config& cfg) override {
    rate_ = static_cast<float>(rate);
    ratios_.clear();
    for (double v : cfg_arr(cfg, "ratios"))
      ratios_.push_back(std::min(static_cast<float>(v), 64.0f));
    int m;
    if (ratios_.empty()) {
      m = static_cast<int>(cfg_num(cfg, "modes", 64.0));
      m = std::clamp(m, 2, 128);
    } else {
      m = static_cast<int>(ratios_.size());
    }
    m += m & 1;  // Rings requires an even resolution; an odd ratios count
                 // pads with an inert mode parked at the 0.49 ceiling.
    modes_.assign(static_cast<std::size_t>(m), resonate::Svf{});

(rest of `init()` unchanged). In `update_block()`, replace the placement loop — from `int num = 0;` through the loop's closing brace — with:

```cpp
    int num = 0;
    const int m = static_cast<int>(modes_.size());
    const int nr = static_cast<int>(ratios_.size());
    // With explicit ratios, structure stretches/compresses the listed
    // series: f_i = f0 * ratios[i]^w, w = 1 at the 0.25 default so the
    // ratios sound exactly as written (spec 2026-07-18-drumkit §2).
    const float warp = std::exp2((structure - 0.25f) * 2.0f);
    for (int i = 0; i < m; ++i) {
      float pf;
      if (nr > 0) {
        pf = i < nr
                 ? f * std::pow(ratios_[static_cast<std::size_t>(i)], warp)
                 : 0.49f;
      } else {
        pf = harmonic * stretch;
      }
      if (pf >= 0.49f) {
        pf = 0.49f;
      } else {
        num = i + 1;
      }
      auto& mode = modes_[static_cast<std::size_t>(i)];
      mode.set_f_q_fast(pf, 1.0f + pf * q);
      mode.flush_denormals();
      stretch += stiffness;
      stiffness *= stiffness < 0.0f ? 0.93f : 0.98f;
      q_loss += q_loss_rate * (1.0f - q_loss);
      harmonic += f;
      q *= q_loss;
    }
```

`copy_state_from` needs no change: `ratios_` is config state rebuilt by `init()`, and the existing `min(size)` prefix copy already migrates differing bank sizes.

# check_wav.py <file.wav> [peak_lo] [peak_hi] -- float32 WAV peak gate.
import struct, sys

raw = open(sys.argv[1], "rb").read()
assert raw[:4] == b"RIFF" and raw[8:12] == b"WAVE", "not a WAV"
pos, fmt, data = 12, None, None
while pos + 8 <= len(raw):
    cid = raw[pos:pos + 4]
    sz = struct.unpack("<I", raw[pos + 4:pos + 8])[0]
    body = raw[pos + 8:pos + 8 + sz]
    if cid == b"fmt ":
        fmt = struct.unpack("<HHIIHH", body[:16])
    if cid == b"data":
        data = body
    pos += 8 + sz + (sz & 1)
tag, nch, rate = fmt[0], fmt[1], fmt[2]
assert tag == 3 and fmt[5] == 32, f"expected float32 wav, got tag {tag}"
n = len(data) // 4
x = struct.unpack(f"<{n}f", data)
peak = max(abs(v) for v in x)
lo = float(sys.argv[2]) if len(sys.argv) > 2 else 0.3
hi = float(sys.argv[3]) if len(sys.argv) > 3 else 1.0
print(f"{sys.argv[1]}: peak {peak:.3f}, {n // nch} frames, {nch} ch, {rate} Hz")
assert lo < peak < hi, f"peak {peak:.3f} outside ({lo}, {hi})"
print("OK")
```

# verify_kit.py <kit.wav> -- loop-lock + band checks for the kit demo.
import math, struct, sys

raw = open(sys.argv[1], "rb").read()
assert raw[:4] == b"RIFF" and raw[8:12] == b"WAVE"
pos, fmt, data = 12, None, None
while pos + 8 <= len(raw):
    cid = raw[pos:pos + 4]
    sz = struct.unpack("<I", raw[pos + 4:pos + 8])[0]
    if cid == b"fmt ":
        fmt = struct.unpack("<HHIIHH", raw[pos + 8:pos + 24])
    if cid == b"data":
        data = raw[pos + 8:pos + 8 + sz]
    pos += 8 + sz + (sz & 1)
nch, rate = fmt[1], fmt[2]
n = len(data) // 4
x = struct.unpack(f"<{n}f", data)
mono = [sum(x[i + c] for c in range(nch)) / nch for i in range(0, n, nch)]
peak = max(abs(v) for v in mono)
print(f"frames {len(mono)}  rate {rate}  peak {peak:.3f}")
assert peak < 0.99, "clipping"

def goertzel(sig, hz):
    w = 2.0 * math.pi * hz / rate
    c = 2.0 * math.cos(w)
    s1 = s2 = 0.0
    for v in sig:
        s1, s2 = v + c * s1 - s2, s1
    return math.sqrt(max(s1 * s1 + s2 * s2 - c * s1 * s2, 0.0)) / len(sig)

seg = mono[: rate * 4]
low = goertzel(seg, 48) + goertzel(seg, 96)
mid = goertzel(seg, 190)
high = goertzel(seg, 3000) + goertzel(seg, 5000) + goertzel(seg, 8000)
print(f"bands  low {low:.5f}  mid {mid:.5f}  high {high:.5f}")
assert low > 0 and mid > 0 and high > 0, "a band is silent"

bar = int(60.0 / 126.0 * 4 * rate)          # 91428 samples at 48 kHz
def ac(sig, lag, stride=4):
    m = len(sig) - lag
    num = sum(sig[i] * sig[i + lag] for i in range(0, m, stride))
    ea = sum(sig[i] * sig[i] for i in range(0, m, stride))
    eb = sum(sig[i + lag] * sig[i + lag] for i in range(0, m, stride))
    return num / math.sqrt(ea * eb) if ea and eb else 0.0

on = ac(mono, bar)
off = ac(mono, int(bar * 1.37))
print(f"autocorr  bar {on:.3f}  off-bar {off:.3f}")
assert on > 0.35 and on > off + 0.15, "groove does not lock to the bar"
print("OK")
```
