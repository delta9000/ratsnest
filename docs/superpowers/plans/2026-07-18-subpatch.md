# Subpatch (`sub`/`subdef`) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Instantiable subpatches — reusable voices with declared ports/params, stamped into the using patch at compile time — per `docs/superpowers/specs/2026-07-18-subpatch-design.md`.

**Architecture:** A compile-time AST expansion pass (`expand_subs`) exactly parallel to `expand_voices`: parse the subpatch source, substitute params, splice `input`/`output` pseudo-modules, prefix names with the instance name, and merge into the main AST *before* `graph::compile`. The graph compiler, reload diff, and RT engine never see subpatches. Five pseudo-module types (`sub`, `subdef`, `param`, `input`, `output`) ride the existing grammar; the only parser change is accepting an identifier as cable depth.

**Tech Stack:** C++20, doctest, std::filesystem. No new dependencies.

## Global Constraints

- External deps stay exactly two: PipeWire and doctest (CLAUDE.md rule 7).
- `expand_subs` runs only on the non-RT path (parse→compile); nothing here may be reachable from `Module::process()` (rule 3).
- Expansion order must be deterministic (template decl order, sub-decl position preserved) so hot reload's structure diff is stable across identical compiles.
- Errors never kill the session: every failure appends `file:line:col` diagnostics and leaves the input AST **unmodified** (rule 6; same contract as `expand_voices`).
- On any error path the AST is untouched — implement on a working copy, commit on success.
- Commit prefix conventions: feat/fix/test/docs. Docs updated in the same commit as the behavior they describe. No AI attribution.
- Build/test: `mise run build` (→ `build/`), `mise run test` (ctest), direct doctest filter: `./build/mstests --test-case="<name>"`.
- Signal conventions unchanged (spec §4 of the ratsnest design); this feature adds no runtime signal semantics — an input's `default:` sums onto internal targets exactly as a constant cable would.

```cpp
bool read_text_file(const std::string& path, std::string& out) {
  std::ifstream f(path);
  if (!f) return false;
  std::ostringstream ss;
  ss << f.rdbuf();
  out = ss.str();
  return true;

namespace {

constexpr size_t kMaxDepth = 16;

bool is_iface(const std::string& t) {
  return t == "param" || t == "input" || t == "output";
}

// chain begins with "name." (strictly deeper than name itself)
bool chain_under(const std::string& chain, const std::string& name) {
  return chain.size() > name.size() + 1 &&
         chain.compare(0, name.size(), name) == 0 && chain[name.size()] == '.';
}

const dsl::ParamDecl* find_param(const dsl::ModuleDecl& m, const std::string& n) {
  for (const auto& p : m.params)
    if (p.name == n) return &p;
  return nullptr;
}

using ParamMap = std::unordered_map<std::string, dsl::Value>;

struct Ctx {
  const FileReader& read;
  Diags& errors;
  size_t err0 = 0;
  std::vector<std::string> files;               // first-use order
  std::unordered_set<std::string> file_set;
  std::unordered_map<std::string, dsl::PatchAst> cache;  // path -> parsed
  std::vector<std::string> labels;              // instantiation chain
  std::unordered_set<std::string> stack;        // cycle detection keys

  bool failed() const { return errors.size() != err0; }

  std::string chain() const {
    if (labels.empty()) return "";
    std::string s = " (via ";
    for (size_t i = 0; i < labels.size(); ++i) {
      if (i) s += " -> ";
      s += labels[i];
    }
    return s + ")";
  }
  void err(const std::string& file, int line, int col, std::string msg) {
    errors.push_back({line, col, std::move(msg) + chain(), file});
  }
};

void subst_value(const ParamMap& params, dsl::Value& v) {
  if (v.kind == dsl::Value::Kind::Ident) {
    auto it = params.find(v.str);
    if (it != params.end()) v = it->second;
  } else if (v.kind == dsl::Value::Kind::Array) {
    for (auto& item : v.items) subst_value(params, item);
  }
}

// Replace param references throughout `body`: config values (except a
// nested sub's file:/def: keys), constant cable sources, identifier depths.
void substitute(Ctx& ctx, const std::string& file, dsl::PatchAst& body,
                const ParamMap& params) {
  for (auto& m : body.modules)
    for (auto& pd : m.params) {
      if (m.type == "sub" && (pd.name == "file" || pd.name == "def")) continue;
      subst_value(params, pd.value);
    }
  for (auto& c : body.cables) {
    if (!c.src.is_literal) {
      auto it = params.find(c.src.module);
      if (it != params.end()) {
        if (it->second.kind != dsl::Value::Kind::Num) {
          ctx.err(file, c.src.line, c.src.col,
                  "param '" + c.src.module + "' used as a cable source must be a number");
        } else {
          c.src.is_literal = true;
          c.src.literal = it->second.num;
          c.src.module.clear();
        }
      }
    }
    if (!c.depth_ident.empty()) {
      auto it = params.find(c.depth_ident);
      if (it != params.end()) {
        if (it->second.kind != dsl::Value::Kind::Num) {
          ctx.err(file, c.line, c.col,
                  "param '" + c.depth_ident + "' used as a cable depth must be a number");
        } else {
          c.depth = it->second.num;
          c.depth_ident.clear();
        }
      }
    }
  }
}

struct Interface {
  ParamMap params;                                     // declared defaults
  std::vector<std::pair<std::string, double>> inputs;  // name, default; declared order
  std::vector<std::string> outputs;                    // declared order; [0] = default
  bool any() const { return !params.empty() || !inputs.empty() || !outputs.empty(); }
  const double* input_def(const std::string& n) const {
    for (const auto& [name, d] : inputs)
      if (name == n) return &d;
    return nullptr;
  }
  bool is_output(const std::string& n) const {
    return std::find(outputs.begin(), outputs.end(), n) != outputs.end();
  }
};

// Read param/input/output declarations (does not remove them; splice_ports
// deletes them once cables are rewritten).
Interface scan_interface(Ctx& ctx, const std::string& file, const dsl::PatchAst& body) {
  Interface f;
  for (const auto& m : body.modules) {
    if (m.type == "param") {
      const dsl::ParamDecl* d = find_param(m, "default");
      if (!d) {
        ctx.err(file, m.line, m.col, "param '" + m.name + "' requires 'default:'");
        continue;
      }
      f.params.emplace(m.name, d->value);
    } else if (m.type == "input") {
      double def = 0.0;
      if (const dsl::ParamDecl* d = find_param(m, "default")) {
        if (d->value.kind != dsl::Value::Kind::Num)
          ctx.err(file, d->line, d->col, "input '" + m.name + "' default must be a number");
        else
          def = d->value.num;
      }
      f.inputs.emplace_back(m.name, def);
    } else if (m.type == "output") {
      f.outputs.push_back(m.name);
    }
  }
  return f;
}

// Task 3 replaces this with real port splicing. For now: interface
// pseudo-module declarations are simply removed.
void splice_ports(Ctx& ctx, const std::string& file, dsl::PatchAst& parent,
                  const std::string& inst, dsl::PatchAst& body, const Interface& f) {
  (void)ctx; (void)file; (void)parent; (void)inst; (void)f;
  std::vector<dsl::ModuleDecl> keep;
  for (auto& m : body.modules)
    if (!is_iface(m.type)) keep.push_back(std::move(m));
  body.modules = std::move(keep);
}

void expand_in(Ctx& ctx, dsl::PatchAst& ast, const std::string& dir,
               const std::string& file);

// Expand one `sub` decl at parent.modules[idx] and splice the result in.
void do_body(Ctx& ctx, dsl::PatchAst& parent, size_t idx, const dsl::ModuleDecl& decl,
             const std::string& parent_file, dsl::PatchAst body,
             const std::string& body_dir, const std::string& body_file) {
  Interface f = scan_interface(ctx, body_file, body);
  if (ctx.failed()) return;

  ParamMap params = f.params;
  for (const auto& o : decl.params) {
    if (o.name == "file" || o.name == "def") continue;
    auto it = params.find(o.name);
    if (it == params.end())
      ctx.err(parent_file, o.line, o.col,
              "sub '" + decl.name + "' has no param '" + o.name + "'");
    else
      it->second = o.value;
  }
  if (ctx.failed()) return;

  substitute(ctx, body_file, body, params);
  if (ctx.failed()) return;

  expand_in(ctx, body, body_dir, body_file);  // nested subs
  if (ctx.failed()) return;

  splice_ports(ctx, body_file, parent, decl.name, body, f);
  if (ctx.failed()) return;

  for (auto& m : body.modules) m.name = decl.name + "." + m.name;
  for (auto& c : body.cables) {
    if (!c.src.is_literal) c.src.module = decl.name + "." + c.src.module;
    c.dst.module = decl.name + "." + c.dst.module;
  }
  parent.modules.erase(parent.modules.begin() + static_cast<long>(idx));
  parent.modules.insert(parent.modules.begin() + static_cast<long>(idx),
                        std::make_move_iterator(body.modules.begin()),
                        std::make_move_iterator(body.modules.end()));
  parent.cables.insert(parent.cables.end(),
                       std::make_move_iterator(body.cables.begin()),
                       std::make_move_iterator(body.cables.end()));
}

void instantiate(Ctx& ctx, dsl::PatchAst& parent, size_t idx,
                 const std::string& dir, const std::string& file) {
  const dsl::ModuleDecl decl = parent.modules[idx];  // copy: parent mutates
  const dsl::ParamDecl* pf = find_param(decl, "file");
  const dsl::ParamDecl* pd = find_param(decl, "def");
  if ((pf != nullptr) == (pd != nullptr)) {
    ctx.err(file, decl.line, decl.col,
            "sub '" + decl.name + "' requires exactly one of 'file:' or 'def:'");
    return;
  }
  if (pd) {  // def: templates arrive in Task 4
    ctx.err(file, pd->line, pd->col, "unknown subdef '" + pd->value.str + "'");
    return;
  }
  if (pf->value.kind != dsl::Value::Kind::Str) {
    ctx.err(file, pf->line, pf->col, "sub 'file:' expects a quoted path");
    return;
  }

  const std::filesystem::path p =
      (std::filesystem::path(dir) / pf->value.str).lexically_normal();
  const std::string path = p.string();
  const std::string key = "file:" + path;
  if (ctx.stack.count(key)) {
    ctx.err(file, decl.line, decl.col, "subpatch include cycle at '" + path + "'");
    return;
  }
  if (ctx.stack.size() >= kMaxDepth) {
    ctx.err(file, decl.line, decl.col, "subpatch nesting deeper than 16");
    return;
  }

  auto it = ctx.cache.find(path);
  if (it == ctx.cache.end()) {
    std::string src;
    if (!ctx.read(path, src)) {
      ctx.err(file, pf->line, pf->col, "cannot read subpatch '" + path + "'");
      return;
    }
    auto pr = dsl::parse(src);
    if (!pr.ok()) {
      for (const auto& d : pr.errors) ctx.err(path, d.line, d.col, d.msg);
      return;
    }
    it = ctx.cache.emplace(path, std::move(pr.ast)).first;
    if (ctx.file_set.insert(path).second) ctx.files.push_back(path);
  }

  ctx.stack.insert(key);
  ctx.labels.push_back(decl.name + " at " + (file.empty() ? "patch" : file) + ":" +
                       std::to_string(decl.line));
  do_body(ctx, parent, idx, decl, file, it->second, p.parent_path().string(), path);
  ctx.labels.pop_back();
  ctx.stack.erase(key);
}

// Expand every `sub` decl in `ast`, in place.
void expand_in(Ctx& ctx, dsl::PatchAst& ast, const std::string& dir,
               const std::string& file) {
  for (size_t i = 0; i < ast.modules.size();) {
    if (ast.modules[i].type != "sub") {
      ++i;
      continue;
    }
    instantiate(ctx, ast, i, dir, file);
    if (ctx.failed()) return;
    // The stamped body replaced modules[i]; nested subs inside it were
    // already expanded recursively, so rescanning from i is correct.
  }
}

}  // namespace

SubExpansion expand_subs(dsl::PatchAst& ast, const std::string& patch_dir,
                         const FileReader& read, Diags& errors) {
  SubExpansion out;
  bool any = false;
  for (const auto& m : ast.modules)
    if (m.type == "sub" || m.type == "subdef" || is_iface(m.type)) {
      any = true;
      break;
    }
  if (!any) return out;  // fast path: ordinary patch, zero cost

  Ctx ctx{read, errors, errors.size(), {}, {}, {}, {}, {}};
  dsl::PatchAst work = ast;
  expand_in(ctx, work, patch_dir, "");
  // Top-level implicit instantiation of a subpatch file arrives in Task 6.
  if (!ctx.failed()) {
    ast = std::move(work);
    out.files = std::move(ctx.files);
  }
  return out;
}
```

```cpp
// Splice the interface out of `body`, rewriting cables in `parent` that
// reference the instance's ports. Binding cables (inside the body) declare
// what a port carries:   <in> -> x.p : d     and    y.q -> <out>[.in] : d
// Reference cables (in `parent`) use  <ref>.<in>  as a destination and
// <ref>.<out> (or bare <ref> = first output) as a source, where <ref> is
// `inst`; with `inst` empty (top-level implicit instantiation, parent ==
// body) ports are referenced bare. Depths multiply through the splice.
void splice_ports(Ctx& ctx, const std::string& file, dsl::PatchAst& parent,
                  const std::string& inst, dsl::PatchAst& body, const Interface& f) {
  auto ref = [&](const std::string& port) {
    return inst.empty() ? port : inst + "." + port;
  };
  auto is_input = [&](const std::string& n) { return f.input_def(n) != nullptr; };

  // --- Phase 1: pull binding cables out of the body ------------------------
  std::unordered_map<std::string, std::vector<dsl::CableDecl>> in_targets;
  std::unordered_map<std::string, std::vector<dsl::CableDecl>> out_sources;
  {
    std::vector<dsl::CableDecl> kept;
    for (auto& c : body.cables) {
      const bool src_is_input = !c.src.is_literal && is_input(c.src.module);
      std::string out_name;
      if (f.is_output(c.dst.module)) out_name = c.dst.module;
      else if (c.dst.module.size() > 3 && c.dst.module.rfind(".in") == c.dst.module.size() - 3) {
        std::string head = c.dst.module.substr(0, c.dst.module.size() - 3);
        if (f.is_output(head)) out_name = head;
      }
      if (src_is_input && !out_name.empty()) {
        ctx.err(file, c.line, c.col,
                "cable may not connect input '" + c.src.module +
                "' directly to output '" + out_name + "'");
        return;
      }
      if (src_is_input) in_targets[c.src.module].push_back(c);
      else if (!out_name.empty()) out_sources[out_name].push_back(c);
      else kept.push_back(std::move(c));
    }
    body.cables = std::move(kept);
  }
  // Bindings that read an output from inside, or feed an input from inside,
  // would need port-through-port routing; reject the remaining odd shapes.
  for (const auto& c : body.cables) {
    if (!c.src.is_literal && f.is_output(c.src.module))
      ctx.err(file, c.src.line, c.src.col,
              "output '" + c.src.module + "' cannot be read inside its own subpatch");
    if (is_input(c.dst.module) || (!c.src.is_literal && chain_under(c.src.module, "")) )
      ;  // dst-as-input handled below via reference pass when inst is empty
  }
  if (ctx.failed()) return;

  // --- Phase 2: rewrite reference cables in the parent ---------------------
  // When inst is empty, parent == body and body.cables already excludes the
  // bindings, so iterating parent.cables is correct in both cases.
  auto stamp = [&](const std::string& chain) {
    return inst.empty() ? chain : inst + "." + chain;
  };
  std::vector<dsl::CableDecl> out_cables;
  std::unordered_set<std::string> fed_inputs;
  for (const auto& c : parent.cables) {
    // Expand the source side first (an output read), then the destination
    // side (an input feed) of each resulting cable.
    std::vector<dsl::CableDecl> stage{c};
    if (!c.src.is_literal) {
      std::string out_name;
      if (!inst.empty() && c.src.module == inst) {
        if (f.outputs.empty()) {
          ctx.err(file, c.src.line, c.src.col,
                  "subpatch '" + inst + "' has no outputs");
          return;
        }
        out_name = f.outputs[0];
      } else {
        for (const auto& o : f.outputs)
          if (c.src.module == ref(o)) out_name = o;
      }
      for (const auto& i : f.inputs)
        if (c.src.module == ref(i.first)) {
          ctx.err(file, c.src.line, c.src.col,
                  "input '" + i.first + "' of '" + inst + "' cannot be a source");
          return;
        }
      if (!out_name.empty()) {
        stage.clear();
        for (const auto& s : out_sources[out_name]) {
          dsl::CableDecl nc = c;
          nc.src = s.src;
          if (!nc.src.is_literal) nc.src.module = stamp(s.src.module);
          nc.depth = c.depth * s.depth;
          stage.push_back(std::move(nc));
        }
      }
    }
    for (const auto& sc : stage) {
      std::string in_name;
      for (const auto& i : f.inputs)
        if (sc.dst.module == ref(i.first)) in_name = i.first;
      for (const auto& o : f.outputs) {
        if (sc.dst.module == ref(o)) {
          ctx.err(file, sc.dst.line, sc.dst.col,
                  "output '" + o + "' of '" + inst + "' cannot be a destination");
          return;
        }
        if (chain_under(sc.dst.module, ref(o))) {
          ctx.err(file, sc.dst.line, sc.dst.col, "port '" + o + "' has no members");
          return;
        }
      }
      for (const auto& i : f.inputs)
        if (chain_under(sc.dst.module, ref(i.first))) {
          ctx.err(file, sc.dst.line, sc.dst.col, "port '" + i.first + "' has no members");
          return;
        }
      if (in_name.empty()) {
        out_cables.push_back(sc);
        continue;
      }
      fed_inputs.insert(in_name);
      for (const auto& t : in_targets[in_name]) {
        dsl::CableDecl nc = sc;
        nc.dst = t.dst;
        nc.dst.module = stamp(t.dst.module);
        nc.depth = sc.depth * t.depth;
        out_cables.push_back(std::move(nc));
      }
    }
  }

  // --- Phase 3: defaults for unpatched inputs ------------------------------
  for (const auto& [name, def] : f.inputs) {
    if (fed_inputs.count(name) || def == 0.0) continue;
    for (const auto& t : in_targets[name]) {
      dsl::CableDecl nc = t;
      nc.src = {};
      nc.src.is_literal = true;
      nc.src.literal = def;
      nc.dst.module = stamp(t.dst.module);
      out_cables.push_back(std::move(nc));
    }
  }
  parent.cables = std::move(out_cables);

  // --- Phase 4: drop the pseudo-module declarations ------------------------
  std::vector<dsl::ModuleDecl> keep;
  for (auto& m : body.modules)
    if (!is_iface(m.type)) keep.push_back(std::move(m));
  body.modules = std::move(keep);
}
```

```cpp
// Collect `name = subdef {}` templates: gather every `name.*` declaration
// and every cable whose endpoints are both inside `name.*` (or a literal
// source), strip the prefix, and remove them all from `ast`. Config Ident
// values and identifier depths of the form "name.x" are stripped too (the
// body references its params with the prefix; stamping removes it).
std::unordered_map<std::string, dsl::PatchAst> collect_subdefs(
    Ctx& ctx, const std::string& file, dsl::PatchAst& ast) {
  std::unordered_map<std::string, dsl::PatchAst> out;
  std::vector<std::pair<std::string, int>> order;  // name, decl line
  for (const auto& m : ast.modules) {
    if (m.type != "subdef") continue;
    if (m.name.find('.') != std::string::npos) {
      ctx.err(file, m.line, m.col, "subdef '" + m.name + "' may not be nested (dotted name)");
      continue;
    }
    out.emplace(m.name, dsl::PatchAst{});
    order.emplace_back(m.name, m.line);
  }
  if (out.empty() || ctx.failed()) return out;

  auto owner = [&](const std::string& chain) -> std::string {
    for (const auto& [name, line] : order)
      if (chain_under(chain, name)) return name;
    return "";
  };
  auto strip = [](const std::string& chain, const std::string& prefix) {
    return chain.substr(prefix.size() + 1);
  };

  std::vector<dsl::ModuleDecl> keep_m;
  for (auto& m : ast.modules) {
    if (m.type == "subdef") continue;  // marker removed
    std::string g = owner(m.name);
    if (g.empty()) {
      keep_m.push_back(std::move(m));
      continue;
    }
    dsl::ModuleDecl copy = std::move(m);
    copy.name = strip(copy.name, g);
    for (auto& p : copy.params) {
      if (p.value.kind == dsl::Value::Kind::Ident && chain_under(p.value.str, g))
        p.value.str = strip(p.value.str, g);
      if (p.value.kind == dsl::Value::Kind::Array)
        for (auto& item : p.value.items)
          if (item.kind == dsl::Value::Kind::Ident && chain_under(item.str, g))
            item.str = strip(item.str, g);
    }
    out[g].modules.push_back(std::move(copy));
  }
  ast.modules = std::move(keep_m);

  std::vector<dsl::CableDecl> keep_c;
  for (auto& c : ast.cables) {
    std::string sg = c.src.is_literal ? "" : owner(c.src.module);
    std::string dg = owner(c.dst.module);
    if (sg.empty() && dg.empty()) {
      keep_c.push_back(std::move(c));
      continue;
    }
    if (sg != dg && !(c.src.is_literal && !dg.empty())) {
      ctx.err(file, c.line, c.col,
              "cable crosses subdef '" + (sg.empty() ? dg : sg) + "' boundary");
      continue;
    }
    dsl::CableDecl copy = std::move(c);
    if (!copy.src.is_literal) copy.src.module = strip(copy.src.module, dg);
    copy.dst.module = strip(copy.dst.module, dg);
    if (!copy.depth_ident.empty() && chain_under(copy.depth_ident, dg))
      copy.depth_ident = strip(copy.depth_ident, dg);
    out[dg].cables.push_back(std::move(copy));
  }
  ast.cables = std::move(keep_c);

  for (const auto& [name, line] : order)
    if (out.count(name) && out[name].modules.empty())
      ctx.err(file, line, 0, "subdef '" + name + "' has no members");
  return out;
}
```

```cpp
// Demo sections (spec §2). A subpatch file may carry `demo.*` declarations
// that compile only when the file is the top-level patch; `demo.out` is the
// ordinary device sink there. Instantiated, the whole demo section drops.
// In both modes a non-demo reference to `out`, or an interface
// pseudo-module under the demo prefix, is an error.
void handle_demo(Ctx& ctx, const std::string& file, dsl::PatchAst& body, bool top) {
  auto in_demo = [](const std::string& chain) {
    return chain == "demo" || chain_under(chain, "demo");
  };
  for (const auto& m : body.modules)
    if (is_iface(m.type) && in_demo(m.name))
      ctx.err(file, m.line, m.col,
              "'" + m.name + "': interface declarations may not live under demo.*");
  for (const auto& c : body.cables) {
    auto bad_out = [&](const dsl::Endpoint& e) {
      if (e.is_literal) return false;
      return e.module == "out" || chain_under(e.module, "out");
    };
    if (bad_out(c.src) || bad_out(c.dst))
      ctx.err(file, c.line, c.col,
              "subpatch bodies may not reference 'out' (use demo.out in a demo section)");
  }
  if (ctx.failed()) return;

  if (top) {
    for (auto& c : body.cables) {
      auto rename = [](dsl::Endpoint& e) {
        if (e.is_literal) return;
        if (e.module == "demo.out") e.module = "out";
        else if (chain_under(e.module, "demo.out"))
          e.module = "out" + e.module.substr(std::string("demo.out").size());
      };
      rename(c.src);
      rename(c.dst);
    }
    return;
  }
  std::vector<dsl::ModuleDecl> keep_m;
  for (auto& m : body.modules)
    if (!in_demo(m.name)) keep_m.push_back(std::move(m));
  body.modules = std::move(keep_m);
  std::vector<dsl::CableDecl> keep_c;
  for (auto& c : body.cables) {
    const bool touches = (!c.src.is_literal && in_demo(c.src.module)) || in_demo(c.dst.module);
    if (!touches) keep_c.push_back(std::move(c));
  }
  body.cables = std::move(keep_c);
}
```

```cpp
PatchWatcher::PatchWatcher(std::vector<std::string> paths) {
  fd_ = inotify_init1(IN_NONBLOCK | IN_CLOEXEC);
  for (const auto& path : paths) {
    std::filesystem::path p(path);
    const std::string dir = p.has_parent_path() ? p.parent_path().string() : ".";
    const std::string base = p.filename().string();
    DirWatch* w = nullptr;
    for (auto& existing : watches_)
      if (existing.dir == dir) w = &existing;
    if (!w) {
      watches_.push_back({-1, dir, {}});
      w = &watches_.back();
    }
    w->bases.insert(base);
  }
  if (fd_ >= 0)
    for (auto& w : watches_) arm(w);
}

bool PatchWatcher::ok() const {
  if (fd_ < 0 || watches_.empty()) return false;
  for (const auto& w : watches_)
    if (w.wd < 0) return false;
  return true;
}

void PatchWatcher::arm(DirWatch& w) {
  if (w.wd >= 0) inotify_rm_watch(fd_, w.wd);  // see single-file note: inode-based
  w.wd = inotify_add_watch(fd_, w.dir.c_str(), kDirMask);
}

void PatchWatcher::drain() {
  alignas(inotify_event) char buf[sizeof(inotify_event) + NAME_MAX + 1];
  ssize_t n = 0;
  while ((n = read(fd_, buf, sizeof(buf))) > 0) {
    for (char* ptr = buf; ptr < buf + n;) {
      const auto* ev = reinterpret_cast<const inotify_event*>(ptr);
      for (auto& w : watches_) {
        if (ev->wd != w.wd) continue;
        if (ev->mask & (IN_MOVE_SELF | IN_DELETE_SELF)) {
          arm(w);
        } else if ((ev->mask & (IN_CLOSE_WRITE | IN_MOVED_TO)) && ev->len > 0 &&
                   w.bases.count(ev->name)) {
          pending_ = true;
          deadline_ = std::chrono::steady_clock::now() + kDebounce;
        }
        break;
      }
      ptr += sizeof(inotify_event) + ev->len;
    }
  }
}
```

```cpp
namespace {
// Single-bin DFT magnitude (same tool test_modal.cpp uses).
double goertzel(const std::vector<float>& x, double hz, double rate = 48000.0) {
  const double w = 2.0 * 3.14159265358979323846 * hz / rate;
  const double coeff = 2.0 * std::cos(w);
  double s0 = 0.0, s1 = 0.0, s2 = 0.0;
  for (float v : x) {
    s0 = v + coeff * s1 - s2;
    s2 = s1;
    s1 = s0;
  }
  return std::sqrt(s1 * s1 + s2 * s2 - coeff * s1 * s2);
}
}  // namespace
```

```markdown
A subpatch is a reusable voice in its own file (convention:
```

Add five sections before `## Recipes` (matching the house one-paragraph style):

```markdown
## `sub`

`k = sub { file: "lib/kick.sub", tune: G1 }` — instantiate a subpatch.
Exactly one of `file:` (quoted path, relative to the file containing the
`sub`) or `def:` (an in-file `subdef` name); every other key overrides a
`param` of that template (unknown keys are errors). Instance ports patch
like module ports (`clk -> k.trig`, `k.main -> mix.in1`; bare `k` reads the
first declared output). Stamped internals stay addressable
(`0.1 -> k.kosc.v_oct`) — the declared interface is the stable surface, not
a wall. Same file, different params: separate instances, one parse.
Nesting is fine (16 deep, cycles rejected); `sub` composes with `voice`
groups in both directions. Saving an included `.sub` hot-reloads every
patch using it.

## `subdef`

`td = subdef {}` — mark the `td.*` declarations that follow as an inline
template: they never run themselves, and `t = sub { def: td, tune: A2 }`
stamps them. Inside the body, params and ports are referenced with the
prefix (`freq: td.tune`); cables may not cross the template boundary. The
`demo.*` convention does not apply to inline templates.

## `param`

`tune = param { default: F1 }` — a subpatch parameter (config `default:`
required). Referenced by bare name in any config value, as a constant cable
source (`tune -> osc.v_oct`), or as a cable depth (`a -> b.in : tune`).
Instantiation overrides replace the default before the body compiles; a
`param` is a compile-time value, not a signal.

## `input`

`trig = input {}` — a subpatch input port (optional numeric `default:`,
read when no outside cable feeds the port — rule 4, nothing implicit
beyond the declaration). Inside the body it is a source
(`trig -> env.trig`); outside, a destination (`clk -> k.trig`). Multiple
outside cables sum; depths multiply through the splice.

## `output`

`main = output {}` — a subpatch output port. Inside, a destination
(`amp -> main.in`); outside, a source (`k.main -> mix.in1`). The first
declared output is the instance's default (`k -> mix.in1`). Declaring
`param`/`input`/`output` makes the file a subpatch: it cannot reference
`out` outside a `demo.*` section, and compiled directly it plays as an
implicit instantiation with defaults — `demo.*` declarations (with
`demo.out` as the device sink) run only then, so every `.sub` can audition
itself: `mise run play -- patches/lib/kick.sub`.
```
