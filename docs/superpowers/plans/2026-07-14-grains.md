# grains (granular processor) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add `grains` — a Clouds-core granular processor (record/freeze ring buffer + grain scheduler + 64-voice windowed-resampling grain player), mono in / stereo out, with WAV file mode; all blend/post-fx compose from existing modules.

**Architecture:** One module in the existing `ms::dsp::Module` framework, per-sample `process()`. A power-of-two mask-indexed ring (like `delay`) records `in` unless frozen; a fixed pool of 64 grains is seeded by an internal density/jitter clock and/or rising edges on `trig`; each grain latches all parameters at onset and renders windowed (boxcar→triangle→Hann morph) cubic-Hermite reads panned equal-power onto `out_l`/`out_r`, with `1/√N` loudness normalization. `file:` config swaps the ring for a static resampled WAV. No engine changes.

**Tech Stack:** C++20, doctest, CMake (globbed sources/tests — no CMake edits needed), `ms::dsp` module framework, `dsp/mastering.h` helpers (`sanitize`, `sanitize_clamp`, `flush_denormal`), `io/wav.h` (`read_wav_f32`, `write_wav_f32` for test fixtures).

**Spec:** `docs/superpowers/specs/2026-07-14-grains-design.md` (read it first; the placement/margin math and window morph are specified there and mirrored in code comments below).

## Global Constraints

- **RT safety (design rule 3):** `process()` never allocates, locks, or does I/O. All buffers are sized in `init()` (control thread); the grain pool is a fixed `std::array`; seeds drop silently when the pool is full — no stealing, no allocation.
- **Signal conventions (design rule 8):** audio ±1; gates rise through 0.5; `pitch` is v/oct; `onset` is a one-sample 1.0 pulse.
- **No normalling (design rule 4):** unpatched inputs read their declared defaults; nothing implicit.
- **External deps (design rule 7):** PipeWire + doctest only. Add none.
- **Determinism:** all randomness from a xorshift32 seeded by the `seed` config; equal seeds + equal inputs ⇒ bit-identical outputs.
- **Errors never kill the session (rule 6):** a missing/unreadable `file:` yields a silent buffer.
- **Hot reload:** `copy_state_from` migrates the ring, grain pool, RNG, and scheduler so frozen textures and sounding grains ride through a patch edit.
- **CI gate:** `mise run ci` builds warnings-as-errors. No unused variables/includes.
- **Docs are part of the diff:** the `grains` entry in `docs/modules.md` lands in the same commit as registration (Task 1) or the `test_docs` registry-coverage test fails. The entry documents the full final surface; behavior fills in across Tasks 2–7 on this branch.

**Build / test commands:**
- Full build: `mise run build`
- Full gate: `mise run test` (build + all ctest)
- Focused unit run: `./build/mstests -tc="grains:*"`
- Sanitized gate (final): `mise run test-san`

**Input index map (used as `ins[i]` everywhere):**
0 `in`, 1 `freeze`, 2 `trig`, 3 `position`, 4 `scatter`, 5 `size`, 6 `pitch`, 7 `density`, 8 `jitter`, 9 `shape`, 10 `spread`, 11 `reverse`. Outputs: 0 `out_l`, 1 `out_r`, 2 `onset`.

#include <algorithm>
#include <array>
#include <cmath>
#include <cstddef>
#include <cstdint>
#include <numbers>
#include <string>
#include <vector>
#include "dsp/mastering.h"
#include "dsp/modules.h"
#include "io/wav.h"

namespace ms::dsp {
namespace {

constexpr InputInfo kIns[] = {
    {"in", 0.f},      {"freeze", 0.f}, {"trig", 0.f},    {"position", 0.5f},
    {"scatter", 0.f}, {"size", 0.1f},  {"pitch", 0.f},   {"density", 10.f},
    {"jitter", 0.5f}, {"shape", 0.5f}, {"spread", 0.5f}, {"reverse", 0.f}};
constexpr ConfigInfo kCfg[] = {
    {"secs", nullptr}, {"file", nullptr}, {"seed", nullptr}};
constexpr OutputInfo kOuts[] = {{"out_l"}, {"out_r"}, {"onset"}};

constexpr int kMaxGrains = 64;  // fixed pool, like the Clouds firmware
constexpr int kTail = 256;      // unfreeze crossfade length (~5 ms @ 48 kHz)

// One replay voice. All fields latch at onset (spec §3 "Grain pool");
// trivially copyable so the whole pool migrates with std::array assignment.
struct Grain {
  bool active = false;
  double phase = 0.0;      // absolute sample index (live) / buffer index (file)
  double inc = 1.0;        // signed read increment; negative = reverse
  double env_phase = 0.0;  // 0..1 across the grain
  double env_inc = 0.0;
  float shape = 0.5f;
  float gain_l = 0.0f;
  float gain_r = 0.0f;
};

class Grains final : public Module {
 public:
  void init(double rate, const Config& cfg) override {
    rate_ = static_cast<float>(rate);
    const double secs = std::clamp(cfg_num(cfg, "secs", 4.0), 0.25, 60.0);
    const auto seed = static_cast<uint32_t>(cfg_num(cfg, "seed", 1.0));
    rng_ = seed ? seed : 1u;  // xorshift must never hold zero
    file_mode_ = false;       // the file task replaces this init

    const auto need = static_cast<std::size_t>(secs * rate);
    std::size_t size = 1;
    while (size < need) size <<= 1;
    buf_.assign(size, 0.0f);  // control thread: allocation is legal here
    mask_ = size - 1;
    len_ = size;
    write_abs_ = size;  // start one ring in: read math never goes negative

    grains_ = {};
    tail_.fill(0.0f);
    tail_len_ = 0;
    xfade_pos_ = kTail;
    was_frozen_ = false;
    prev_trig_ = 0.0f;
    countdown_ = 0.0;
    norm_ = 1.0f;
    norm_a_ = 1.0f - std::exp(-1.0f / (0.010f * rate_));
  }

  void process(const float* ins, float* outs) override {
    const float in = sanitize(ins[0]);
    const bool frozen = sanitize(ins[1]) > 0.5f;
    record(in, frozen);
    outs[0] = 0.0f;
    outs[1] = 0.0f;
    outs[2] = 0.0f;
  }

 private:
  // Advance the record head by one sample. The freeze-tail crossfade task
  // replaces this with the click-free version.
  void record(float in, bool frozen) {
    if (file_mode_ || frozen) return;
    buf_[static_cast<std::size_t>(write_abs_) & mask_] = in;
    ++write_abs_;
  }

  float rate_ = 48000.0f;
  bool file_mode_ = false;
  std::vector<float> buf_;
  std::size_t mask_ = 0;
  std::size_t len_ = 0;
  uint64_t write_abs_ = 0;
  std::array<Grain, kMaxGrains> grains_{};
  std::array<float, kTail> tail_{};
  int tail_len_ = 0;
  int xfade_pos_ = kTail;
  bool was_frozen_ = false;
  float prev_trig_ = 0.0f;
  double countdown_ = 0.0;
  uint32_t rng_ = 1;
  float norm_ = 1.0f;
  float norm_a_ = 0.0f;
};

std::unique_ptr<Module> make() { return std::make_unique<Grains>(); }

}  // namespace

const ModuleInfo grains_info{"grains", kIns, kCfg, kOuts, &make};

}  // namespace ms::dsp

## `grains`

`grains { secs: 4, seed: 1 }` — granular processor: the Clouds core (record/
freeze buffer + grain scheduler + 64-voice grain player) with the blend
section left to cables (`xfade`/`mix` for dry/wet, `delay` or a patched
feedback loop, `reverb`, `stereo`). Mono `in`, stereo out. Inputs: `in` 0,
`freeze` gate 0 (halts recording; grains keep reading; unfreeze crossfades
back over ~5 ms), rising-edge `trig` (seeds exactly one grain), `position`
0.5 (0 = newest audio / file start, 1 = oldest / file end — freezing never
re-maps it), `scatter` 0 (per-grain random position offset), `size` 0.1 s
(5 ms..2 s, capped at a quarter buffer), `pitch` 0 v/oct (±4 oct, plain
resampling — upward shifts alias, like the hardware), `density` 10 grains/s
(0..200; 0 = external `trig` only), `jitter` 0.5 (0 = periodic stream, 1 =
Poisson cloud; the mean rate stays `density`), `shape` 0.5 (window morph:
0 boxcar → 0.5 triangle → 1 Hann), `spread` 0.5 (random pan width; 0 =
center), `reverse` gate (latched per grain; plays the window backward).
Outputs `out_l`, `out_r`, and a one-sample `onset` pulse per seeded grain.
Configs: `secs` buffer length 0.25..60 s; `file` (quoted WAV path) preloads
the buffer, disables the record head, and makes `in`/`freeze` inert (missing
file = silence); `seed` makes every random draw repeatable. All grain
parameters latch at onset, so `sh`/`random` into `position`/`pitch` with a
clocked `trig` gives per-grain modulation compositionally. Extra seeds beyond
64 voices drop silently; output is loudness-normalized (`1/√N`). Determinism
means two instances fed the same input and freeze gate hold identical
buffers — multi-player-per-buffer patches for free.

```text
g = grains { secs: 4, seed: 7 }
src -> g.in
hold -> g.freeze
drift -> g.position : 0.3
g.out_l -> verb.in_l : 0.8
g.out_r -> verb.in_r : 0.8
```

```cpp
  void process(const float* ins, float* outs) override {
    const float in = sanitize(ins[0]);
    const bool frozen = sanitize(ins[1]) > 0.5f;
    const float trig = sanitize(ins[2]);

    record(in, frozen);

    // External trig: exactly one grain per rising edge, any density.
    bool seeded = false;
    if (prev_trig_ <= 0.5f && trig > 0.5f) seeded = seed_grain(ins);
    prev_trig_ = trig;
    seeded = schedule(ins) || seeded;

    float sum_l = 0.0f;
    float sum_r = 0.0f;
    int active = 0;
    for (Grain& g : grains_) {
      if (!g.active) continue;
      ++active;
      const float w = window(static_cast<float>(g.env_phase), g.shape);
      const float s = read(g.phase) * w;
      sum_l += s * g.gain_l;
      sum_r += s * g.gain_r;
      g.phase += g.inc;
      g.env_phase += g.env_inc;
      if (g.env_phase >= 1.0) g.active = false;
    }

    // Loudness normalization: grain count + window energy (Clouds), smoothed
    // ~10 ms so births/deaths don't step the gain.
    const float shape_now = sanitize_clamp(ins[9], 0.0f, 1.0f, 0.5f);
    const float target = std::min(1.0f + 2.0f * shape_now, 2.0f) /
                         std::sqrt(static_cast<float>(std::max(active, 1)));
    norm_ += norm_a_ * (target - norm_);
    norm_ = flush_denormal(norm_);

    outs[0] = sum_l * norm_;
    outs[1] = sum_r * norm_;
    outs[2] = seeded ? 1.0f : 0.0f;
  }
```

```cpp
  // Internal density/jitter clock; the scheduler task fills this in.
  bool schedule(const float* /*ins*/) { return false; }

  // Latch one grain from the current input values. Returns false when the
  // pool is saturated (seeds drop silently, like the hardware).
  bool seed_grain(const float* ins) {
    Grain* g = nullptr;
    for (Grain& c : grains_) {
      if (!c.active) {
        g = &c;
        break;
      }
    }
    if (g == nullptr) return false;

    const float size_s = sanitize_clamp(ins[5], 0.005f, 2.0f, 0.1f);
    const float pitch = sanitize_clamp(ins[6], -4.0f, 4.0f);
    const float shape = sanitize_clamp(ins[9], 0.0f, 1.0f, 0.5f);
    const float spread = sanitize_clamp(ins[10], 0.0f, 1.0f, 0.5f);
    const bool reverse = sanitize(ins[11]) > 0.5f;
    const float pos = sanitize_clamp(ins[3], 0.0f, 1.0f, 0.5f);

    const double len = static_cast<double>(len_);
    const double ratio = std::exp2(static_cast<double>(pitch));
    double dur = static_cast<double>(size_s) * static_cast<double>(rate_);
    double span = dur * std::max(ratio, 1.0);  // buffer distance covered
    if (span > len * 0.25) {  // keep every grain inside a quarter ring
      dur *= (len * 0.25) / span;
      span = len * 0.25;
    }

    // Placement (spec §3): margins guarantee the read head never crosses the
    // moving record head nor out-runs the oldest sample.
    double start;
    if (file_mode_) {
      start = 4.0 + static_cast<double>(pos) * std::max(len - span - 8.0, 0.0);
    } else {
      const double available = std::max(len - 2.0 * span - 8.0, 0.0);
      const double delay = static_cast<double>(pos) * available + span + 4.0;
      start = static_cast<double>(write_abs_) - delay;
    }

    g->active = true;
    g->phase = reverse ? start + span : start;
    g->inc = reverse ? -ratio : ratio;
    g->env_phase = 0.0;
    g->env_inc = 1.0 / std::max(dur, 1.0);
    g->shape = shape;
    const float pan = 0.5f + spread * (frand() - 0.5f);
    const float angle = pan * (std::numbers::pi_v<float> / 2.0f);
    g->gain_l = std::cos(angle);
    g->gain_r = std::sin(angle);
    return true;
  }

  // Window morph (Clouds Grain::RenderEnvelope): folded triangle; below 0.5
  // the slopes steepen toward a boxcar, above 0.5 it blends toward a
  // raised-cosine of the triangle -> Hann at 1.
  static float window(float p, float shape) {
    const float tri = 1.0f - std::abs(2.0f * p - 1.0f);
    if (shape < 0.5f) {
      return std::min(tri * (0.5f / (shape + 0.01f)), 1.0f);
    }
    const float rc = 0.5f - 0.5f * std::cos(std::numbers::pi_v<float> * tri);
    return tri + (2.0f * shape - 1.0f) * (rc - tri);
  }

  // 4-point cubic Hermite read; masked ring indexing makes wrap branch-free
  // (the file task adds a clamped branch for the non-ring buffer).
  float read(double idx) const {
    const auto i1 = static_cast<uint64_t>(idx);
    const float f = static_cast<float>(idx - static_cast<double>(i1));
    const float x0 = buf_[static_cast<std::size_t>(i1 - 1) & mask_];
    const float x1 = buf_[static_cast<std::size_t>(i1) & mask_];
    const float x2 = buf_[static_cast<std::size_t>(i1 + 1) & mask_];
    const float x3 = buf_[static_cast<std::size_t>(i1 + 2) & mask_];
    return hermite(x0, x1, x2, x3, f);
  }

  static float hermite(float x0, float x1, float x2, float x3, float f) {
    const float c1 = 0.5f * (x2 - x0);
    const float c2 = x0 - 2.5f * x1 + 2.0f * x2 - 0.5f * x3;
    const float c3 = 0.5f * (x3 - x0) + 1.5f * (x1 - x2);
    return ((c3 * f + c2) * f + c1) * f + x1;
  }

  // xorshift32 in [0, 1): deterministic per the seed config.
  float frand() {
    rng_ ^= rng_ << 13;
    rng_ ^= rng_ >> 17;
    rng_ ^= rng_ << 5;
    return static_cast<float>(rng_ >> 8) * (1.0f / 16777216.0f);
  }

  // Internal clock (spec §3 "Scheduling"): after each internal seed the next
  // onset is drawn as dt = base * ((1 - jitter) + jitter * (-ln u)). Since
  // E[-ln u] = 1, the mean rate is exactly `density` for every jitter;
  // jitter 0 is a synchronous stream, jitter 1 a Poisson cloud.
  bool schedule(const float* ins) {
    const float density = sanitize_clamp(ins[7], 0.0f, 200.0f);
    if (density <= 0.0f) return false;
    bool seeded = false;
    if (countdown_ <= 0.0) {
      seeded = seed_grain(ins);
      const float jitter = sanitize_clamp(ins[8], 0.0f, 1.0f, 0.5f);
      const double base =
          static_cast<double>(rate_) / static_cast<double>(density);
      const double u = 1.0 - static_cast<double>(frand());  // (0, 1]
      const double dt = base * ((1.0 - static_cast<double>(jitter)) +
                                static_cast<double>(jitter) * -std::log(u));
      countdown_ += std::max(dt, 1.0);
    }
    countdown_ -= 1.0;
    return seeded;
  }

      if (io::read_wav_f32(file, w) && w.frames > 0 && w.channels > 0) {
        const auto ch = static_cast<std::size_t>(w.channels);
        std::vector<float> mixed(w.frames);
        for (std::size_t fr = 0; fr < w.frames; ++fr) {
          float acc = 0.0f;
          for (std::size_t c = 0; c < ch; ++c) acc += w.samples[fr * ch + c];
          mixed[fr] = acc / static_cast<float>(ch);
        }
        const double step = static_cast<double>(w.sample_rate) / rate;
        const auto out_n = std::min(
            static_cast<std::size_t>(static_cast<double>(w.frames) / step),
            static_cast<std::size_t>(60.0 * rate));
        mono.resize(out_n);
        for (std::size_t i = 0; i < out_n; ++i) {
          const double p = static_cast<double>(i) * step;
          const auto i0 = static_cast<std::size_t>(p);
          const float f = static_cast<float>(p - static_cast<double>(i0));
          const float a = mixed[i0];
          const float b = (i0 + 1 < w.frames) ? mixed[i0 + 1] : a;
          mono[i] = a + (b - a) * f;
        }
      }
      if (mono.size() < 4096) mono.resize(4096, 0.0f);  // silent floor
      len_ = mono.size();
      buf_ = std::move(mono);
      mask_ = 0;       // unused: file reads clamp instead of wrapping
      write_abs_ = 0;  // no record head
    } else {
      const auto need = static_cast<std::size_t>(secs * rate);
      std::size_t size = 1;
      while (size < need) size <<= 1;
      buf_.assign(size, 0.0f);  // control thread: allocation is legal here
      mask_ = size - 1;
      len_ = size;
      write_abs_ = size;  // one ring in: read math never goes negative
    }

    grains_ = {};
    tail_.fill(0.0f);
    tail_len_ = 0;
    xfade_pos_ = kTail;
    was_frozen_ = false;
    prev_trig_ = 0.0f;
    countdown_ = 0.0;
    norm_ = 1.0f;
    norm_a_ = 1.0f - std::exp(-1.0f / (0.010f * rate_));
  }
```

      const float f = static_cast<float>(c - static_cast<double>(i1));

  void copy_state_from(const Module& other) override {
    const auto& o = static_cast<const Grains&>(other);
    // RT-called: bounded copy, no allocation (delay precedent; ~1 MB at the
    // default 4 s ring). Sizes match unless a secs edit resized the ring.
    const std::size_t n = std::min(buf_.size(), o.buf_.size());
    std::copy_n(o.buf_.begin(), n, buf_.begin());
    write_abs_ = o.write_abs_;
    prev_trig_ = o.prev_trig_;
    was_frozen_ = o.was_frozen_;
    tail_ = o.tail_;
    tail_len_ = o.tail_len_;
    xfade_pos_ = o.xfade_pos_;
    rng_ = o.rng_;
    countdown_ = o.countdown_;
    norm_ = o.norm_;
    grains_ = o.grains_;
    // A resize may have shrunk the ring: kill grains that no longer fit.
    for (Grain& g : grains_) {
      if (!g.active) continue;
      if (file_mode_) {
        if (g.phase >= static_cast<double>(len_)) g.active = false;
      } else if (static_cast<double>(write_abs_) - g.phase >
                 static_cast<double>(len_) - 8.0) {
        g.active = false;
      }
    }
  }
