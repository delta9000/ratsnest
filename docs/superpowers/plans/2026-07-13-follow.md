# Follow (envelope follower) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a `follow` module — the audio→CV bridge — that measures an audio signal's amplitude envelope and emits it as a control voltage plus a threshold gate.

**Architecture:** A single mono-input module in the existing `Module` framework. It rectifies `in` (peak `|in|` or RMS `in²`, chosen by a `mode` config), smooths it with an asymmetric one-pole attack/release detector in the linear domain, and outputs `env` (linear amplitude) and `gate` (a hysteretic comparison of `env` against a `thresh` input). No file/PipeWire I/O — pure DSP, so no engine changes.

**Tech Stack:** C++20, doctest, CMake (globbed sources/tests), the `ms::dsp` module framework, and the `dsp/mastering.h` helpers (`sanitize`, `sanitize_clamp`, `flush_denormal`, `OnePole`).

**Spec:** `docs/superpowers/specs/2026-07-13-follow-design.md`

## Global Constraints

- **RT safety (design rule 3):** `process()` never allocates, locks, or does I/O. Same for anything it calls. `follow` uses only stack floats and the header-only helpers.
- **Signal conventions (design rule 8 / spec §4):** `env` is unipolar (`≥ 0`, `0..1` for input within ±1, unclamped above). `gate` is high above `0.5` (emit exactly `1.0` / `0.0`).
- **No normalling (design rule 4):** unpatched inputs read their declared defaults; nothing implicit.
- **External deps (design rule 7):** PipeWire + doctest only. Add none.
- **Determinism & hot reload:** runtime state migrates by (name, type); `follow`'s state must survive reload.
- **CI gate:** `mise run ci` builds warnings-as-errors. No unused variables/includes.
- **Docs are part of the diff:** the `follow` entry in `docs/modules.md` lands in the same commit as the code (the `test_docs.cpp` registry-coverage test fails otherwise).

**Build / test commands:**
- Full build: `mise run build`
- Full gate: `mise run test` (build + all ctest)
- Focused unit run: `./build/mstests -tc="follow:*"`
- Sanitized gate (final): `mise run test-san`

```cpp
using namespace ms::dsp;

namespace {
std::unique_ptr<Module> make_follow(double rate = 48000.0,
                                    const char* mode = "peak") {
  const ModuleInfo* info = find_module("follow");
  REQUIRE(info != nullptr);
  auto m = info->create();
  Config cfg;
  if (mode) cfg.push_back({"mode", ConfigValue{std::string(mode), 0.0, {}, false}});
  m->init(rate, cfg);
  return m;
}
}  // namespace

TEST_CASE("follow: metadata and defaults") {
  const ModuleInfo* info = find_module("follow");
  REQUIRE(info != nullptr);
  CHECK(std::string(info->type) == "follow");

  REQUIRE(info->inputs.size() == 4);
  CHECK(std::string(info->inputs[0].name) == "in");      CHECK(info->inputs[0].def == 0.0f);
  CHECK(std::string(info->inputs[1].name) == "attack");  CHECK(info->inputs[1].def == 0.01f);
  CHECK(std::string(info->inputs[2].name) == "release"); CHECK(info->inputs[2].def == 0.1f);
  CHECK(std::string(info->inputs[3].name) == "thresh");  CHECK(info->inputs[3].def == 0.1f);

  REQUIRE(info->configs.size() == 1);
  CHECK(std::string(info->configs[0].name) == "mode");

  REQUIRE(info->outputs.size() == 2);
  CHECK(std::string(info->outputs[0].name) == "env");
  CHECK(std::string(info->outputs[1].name) == "gate");
}

TEST_CASE("follow: peak envelope converges to DC magnitude") {
  auto m = make_follow(48000.0, "peak");
  float ins[4] = {0.5f, 0.001f, 0.001f, 0.1f};  // fast ballistics
  float outs[2] = {0.0f, 0.0f};
  for (int i = 0; i < 5000; ++i) m->process(ins, outs);
  CHECK(outs[0] == doctest::Approx(0.5f).epsilon(0.01));
}

TEST_CASE("follow: peak envelope reaches full scale on constant input") {
  auto m = make_follow(48000.0, "peak");
  float ins[4] = {1.0f, 0.001f, 0.1f, 0.1f};
  float outs[2] = {0.0f, 0.0f};
  for (int i = 0; i < 5000; ++i) m->process(ins, outs);
  CHECK(outs[0] > 0.99f);
  CHECK(outs[0] <= 1.0001f);
}

TEST_CASE("follow: peak vs rms detection of a full-scale sine") {
  // Slow symmetric ballistics converge to the analytic averages:
  //   peak (mean |sin|) = 2/pi ~= 0.637   rms (sqrt mean sin^2) = 1/sqrt2 ~= 0.707
  const double step = 2.0 * std::numbers::pi * 1000.0 / 48000.0;  // 1 kHz
  for (int mode = 0; mode < 2; ++mode) {
    auto m = make_follow(48000.0, mode == 0 ? "peak" : "rms");
    float ins[4] = {0.0f, 0.05f, 0.05f, 0.1f};
    float outs[2] = {0.0f, 0.0f};
    double ph = 0.0, acc = 0.0;
    int n = 0;
    for (int i = 0; i < 20000; ++i) {
      ins[0] = static_cast<float>(std::sin(ph));
      ph += step;
      m->process(ins, outs);
      if (i >= 19520) { acc += outs[0]; ++n; }
    }
    const double avg = acc / n;
    if (mode == 0) CHECK(avg == doctest::Approx(2.0 / std::numbers::pi).epsilon(0.02));
    else           CHECK(avg == doctest::Approx(1.0 / std::sqrt(2.0)).epsilon(0.02));
  }
}

TEST_CASE("follow: silence produces exact-zero envelope and low gate") {
  auto m = make_follow(48000.0, "peak");
  float ins[4] = {0.0f, 0.01f, 0.1f, 0.1f};
  float outs[2] = {9.9f, 9.9f};
  m->process(ins, outs);
  CHECK(outs[0] == 0.0f);
  CHECK(outs[1] == 0.0f);
}

TEST_CASE("follow: gate has hysteresis around thresh") {
  auto m = make_follow(48000.0, "peak");
  float outs[2] = {0.0f, 0.0f};
  auto settle = [&](float x) {
    float ins[4] = {x, 0.001f, 0.001f, 0.5f};  // thresh 0.5, fast so env ~= |in|
    for (int i = 0; i < 5000; ++i) m->process(ins, outs);
  };
  settle(0.0f);  CHECK(outs[1] == 0.0f);  // below off-threshold: low
  settle(0.4f);  CHECK(outs[1] == 0.0f);  // hold zone (0.375..0.5) from below: stays low
  settle(0.6f);  CHECK(outs[1] == 1.0f);  // above thresh: high
  settle(0.4f);  CHECK(outs[1] == 1.0f);  // hold zone from above: stays high
  settle(0.3f);  CHECK(outs[1] == 0.0f);  // below 0.75*thresh: low
}

TEST_CASE("follow: hostile inputs stay finite") {
  for (double rate : {44100.0, 48000.0, 96000.0}) {
    auto m = make_follow(rate, "rms");
    float outs[2] = {0.0f, 0.0f};
    float bad[4] = {NAN, INFINITY, -1.0f, NAN};
    m->process(bad, outs);
    CHECK(std::isfinite(outs[0]));
    CHECK(std::isfinite(outs[1]));
    float big[4] = {1e12f, 0.01f, 0.1f, 0.1f};
    m->process(big, outs);
    CHECK(std::isfinite(outs[0]));
    CHECK(std::isfinite(outs[1]));
  }
}
```

- [ ] **Step 3: Create the module implementation**

Create `src/dsp/modules/follow.cpp`:

```cpp
#include <cmath>
#include "dsp/modules.h"
#include "dsp/mastering.h"

namespace ms::dsp {
namespace {

constexpr InputInfo kIns[] = {
    {"in", 0.0f},
    {"attack", 0.01f},   // s
    {"release", 0.1f},   // s
    {"thresh", 0.1f},    // unipolar gate threshold
};
constexpr const char* kModes[] = {"peak", "rms", nullptr};
constexpr ConfigInfo kCfg[] = {
    {"mode", kModes},
};
constexpr OutputInfo kOuts[] = {
    {"env"},
    {"gate"},
};

class Follow final : public Module {
 public:
  void init(double rate, const Config& cfg) override {
    rate_ = static_cast<float>(rate);
    is_rms_ = (cfg_str(cfg, "mode", "peak") == "rms");
    state_ = 0.0f;
    gate_high_ = false;
  }

  void process(const float* ins, float* outs) override {
    const float in = sanitize(ins[0], 0.0f);
    const float attack = sanitize_clamp(ins[1], 0.0001f, 10.0f, 0.01f);
    const float release = sanitize_clamp(ins[2], 0.0001f, 10.0f, 0.1f);
    const float thresh = sanitize_clamp(ins[3], 0.0f, 8.0f, 0.1f);

    // 1. Rectify by mode: peak follows |in|, rms follows in^2 (energy).
    const float x = is_rms_ ? in * in : std::abs(in);

    // 2. One-pole ballistics with asymmetric attack/release coefficients.
    const float alpha_a = 1.0f - std::exp(-1.0f / (attack * rate_));
    const float alpha_r = 1.0f - std::exp(-1.0f / (release * rate_));
    state_ += (x > state_ ? alpha_a : alpha_r) * (x - state_);
    state_ = flush_denormal(state_);

    // 3. Envelope: undo the squaring in rms mode. Linear amplitude, >= 0,
    //    intentionally unclamped on top so hot signals read honestly.
    const float env = is_rms_ ? std::sqrt(state_) : state_;

    // 4. Gate with fixed relative hysteresis: on at thresh, off at 75% of it.
    if (env > thresh) {
      gate_high_ = true;
    } else if (env < 0.75f * thresh) {
      gate_high_ = false;
    }

    outs[0] = env;
    outs[1] = gate_high_ ? 1.0f : 0.0f;
  }

 private:
  float rate_ = 48000.0f;
  bool is_rms_ = false;
  float state_ = 0.0f;
  bool gate_high_ = false;
};

std::unique_ptr<Module> make() { return std::make_unique<Follow>(); }

}  // namespace

const ModuleInfo follow_info{"follow", kIns, kCfg, kOuts, &make};

}  // namespace ms::dsp
```

````markdown
## `follow`

`follow { mode: peak }` — envelope follower / audio→CV bridge. Inputs `in` 0,
`attack` 0.01 s, `release` 0.1 s, `thresh` 0.1; outputs unipolar `env` and
`gate`. It rectifies `in` (peak: `|in|`; rms: `in²`), smooths it with an
asymmetric one-pole attack/release detector, and emits the linear amplitude as
`env` (`≥ 0`, `0..1` for input within ±1, unclamped above — a hot signal reads
honestly). `gate` rises when `env` exceeds `thresh` and falls at `0.75 · thresh`
(fixed hysteresis, so it does not chatter near the threshold). Config `mode`:
`peak` (transient-reactive, for ducking off a kick) or `rms` (energy/loudness,
for following a sustained part). No sensitivity knob — scale a weak source at
the cable. Example — audio-derived sidechain duck:

```text
f = follow { mode: peak, attack: 5ms, release: 120ms }
kick -> f.in
pad  -> m.in2
f.env -> m.lvl2 : -0.4
```
````

```cpp
TEST_CASE("follow: copy_state_from migrates envelope and gate latch") {
  auto a = make_follow(48000.0, "peak");
  float ins[4] = {0.7f, 0.001f, 0.001f, 0.1f};  // fast ballistics, thresh 0.1
  float outs[2] = {0.0f, 0.0f};
  for (int i = 0; i < 5000; ++i) a->process(ins, outs);
  const float env_a = outs[0];
  CHECK(env_a > 0.6f);        // settled near 0.7
  CHECK(outs[1] == 1.0f);     // env > thresh so gate latched high

  // A fresh instance continues seamlessly after migration.
  auto b = make_follow(48000.0, "peak");
  b->copy_state_from(*a);
  b->process(ins, outs);
  CHECK(outs[0] == doctest::Approx(env_a).epsilon(0.02));
  CHECK(outs[1] == 1.0f);

  // Without migration it would start from silence (proves migration matters).
  auto c = make_follow(48000.0, "peak");
  c->process(ins, outs);
  CHECK(outs[0] < 0.1f);      // one sample up from zero, far from 0.7
}
```
