# FM voice (`fm`) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking; a task is done only when its named tests pass.

**Goal:** One 6-operator phase-modulation voice module — `fm` — with per-operator 4-segment time/level envelopes, named + custom routing, and a fully patchable live surface, per `docs/superpowers/specs/2026-07-17-fm-design.md`.

**Architecture:** A single ordinary registry module (`src/dsp/modules/fm.cpp`). Config is parsed in `init()` into fixed per-op arrays; routing becomes an edge list (named table or validated `route` pairs, malformed → `free` fallback) that `init()` topologically sorts so modulators evaluate before their targets each sample. Envelopes are a small `adsr`-style state machine per op; feedback self-edges read the op's previous-sample output. No new shared headers, no new dependencies.

**Tech Stack:** C++20, doctest, CMake presets via mise. Sources/tests are CMake-globbed — new files need no CMakeLists edits.

## Global Constraints

- `Module::process()` is called **once per sample** (`ins[i]` = summed input i, `outs[j]` = output j). It must never allocate, lock, or do I/O (design rule 3). Allocation happens in `init()` only (edge/pred vectors).
- `copy_state_from()` is RT-called: bounded copies, no allocation.
- Signal conventions (rule 8): audio ±1, unipolar CV 0..1, `v_oct` octaves, gates rise through 0.5.
- NaN-proof clamps use the `!(x >= lo)` pattern (overdrive precedent), so a NaN control input collapses to a bound instead of poisoning all six ops.
- Double accumulation for envelope progress and op phase (the `adsr`/`vco` contract: float increments stall past 2^25 samples).
- `-Wall -Wextra -Wconversion` is on and `mise run ci` is warnings-as-errors: cast `double`↔`float` explicitly.
- Docs are part of the diff: `tests/test_docs.cpp` requires a `` ## `fm` `` heading in `docs/modules.md` once `fm` is in the registry (Task 6).
- Attribution is part of the diff (CLAUDE.md rules): `fm.cpp` carries a provenance comment and `docs/attribution.md` gains a concept-inspired row (Task 6). No code is copied from anywhere, so `THIRD_PARTY_NOTICES.md` is untouched.
- Every `patches/*.patch` gets an automatic `ratsnest check` ctest — the demo patch must parse.
- Build/test: `mise run build`; run one test file with `cmake --build build -j && ./build/mstests -sf="*test_fm*"`; full gates `mise run test`, `mise run test-san`, `mise run ci`.
- Commits: conventional prefixes (`feat:`/`test:`/`docs:`), tool-agnostic messages, no AI attribution. **Ask the user before each commit** (OpenCode git-mutation rule).
- Tests instantiate modules directly: `find_module("fm")` → `create()` → `init(rate, cfg)` → `process(ins, outs)` (see `tests/test_adsr.cpp`). Sample rate is a `double`; envelope tests use 1000.0 so times map 1 ms = 1 sample.

ConfigValue arr(std::initializer_list<double> v) {
  ConfigValue c;
  c.arr.assign(v.begin(), v.end());

}
ConfigValue str(const char* s) { ConfigValue c; c.str = s; return c; }

struct FmRig {
  std::unique_ptr<Module> m;
  float ins[17] = {};
  float outs[7] = {};

  explicit FmRig(double rate, const Config& cfg = {}) {
    const ModuleInfo* info = find_module("fm");
    REQUIRE(info != nullptr);
    m = info->create();
    m->init(rate, cfg);
    ins[1] = 250.0f;  // freq: rate/4 at 1 kHz -> every 4th sample is |sin| = 1
    ins[3] = 1.0f;    // vel
  }
  void tick(float gate) {
    ins[0] = gate;
    m->process(ins, outs);
  }
  // Envelope reader: run 4 ticks, return max |op1| (the |sin|=1 sample).
  float env4(float gate) {
    float peak = 0.0f;
    for (int i = 0; i < 4; ++i) {
      tick(gate);
      peak = std::max(peak, std::abs(outs[1]));
    }
    return peak;
  }
};
}  // namespace

```cpp
// 6-operator phase-modulation voice after Chowning's published FM formula
// (concept-inspired; see docs/attribution.md). Topology, algorithm set,
// scaling, and envelope design are original to ratsnest — no Yamaha/DX data,
// layouts, or code are used anywhere in this file.
#include <algorithm>
#include <array>
#include <cmath>
#include <numbers>
#include <utility>
#include <vector>
#include "dsp/modules.h"

namespace ms::dsp {
namespace {

constexpr int kOps = 6;
constexpr float kTwoPi = 2.0f * std::numbers::pi_v<float>;
// Phase deviation carried by a level-1 modulator at envelope peak: ±4π rad
// (modulation index ≈ 12.6), the classic instruments' ballpark maximum.
constexpr float kIndex = 4.0f * std::numbers::pi_v<float>;

constexpr InputInfo kIns[] = {
    {"gate", 0.f},   {"freq", 440.f}, {"v_oct", 0.f},  {"vel", 1.f},
    {"lvl1", 0.f},   {"lvl2", 0.f},   {"lvl3", 0.f},   {"lvl4", 0.f},
    {"lvl5", 0.f},   {"lvl6", 0.f},   {"ratio1", 0.f}, {"ratio2", 0.f},
    {"ratio3", 0.f}, {"ratio4", 0.f}, {"ratio5", 0.f}, {"ratio6", 0.f},
    {"fb", 0.f}};
constexpr const char* kAlgos[] = {"free",  "triad", "dual", "cascade",
                                  "crown", "weave", "custom", nullptr};
constexpr const char* kCurves[] = {"lin", "exp", "log", nullptr};
constexpr const char* kSyncs[] = {"on", "off", nullptr};
constexpr ConfigInfo kCfg[] = {
    {"algo", kAlgos},    {"route", nullptr}, {"ratios", nullptr},
    {"levels", nullptr}, {"fixed", nullptr}, {"fb", nullptr},
    {"vel_sens", nullptr},
    {"t1", nullptr},     {"t2", nullptr},    {"t3", nullptr},
    {"t4", nullptr},     {"l1", nullptr},    {"l2", nullptr},
    {"l3", nullptr},     {"curve", kCurves}, {"sync", kSyncs}};
constexpr OutputInfo kOuts[] = {{"out"}, {"op1"}, {"op2"}, {"op3"},
                                {"op4"}, {"op5"}, {"op6"}};

// NaN-proof clamps: NaN collapses to lo.
float clampn(float x, float lo, float hi) {
  if (!(x >= lo)) return lo;
  return x > hi ? hi : x;
}
double clampd(double x, double lo, double hi) {
  if (!(x >= lo)) return lo;
  return x > hi ? hi : x;
}

struct OpEnv {
  enum class Stage { Idle, S1, S2, S3, Hold, Rel };
  Stage stage = Stage::Idle;
  double level = 0.0, start = 0.0, progress = 0.0;
};

struct EnvCfg {
  std::array<double, 4> t{};  // segment times, seconds
  std::array<double, 3> l{};  // S1..S3 target levels
};

double env_shape(int curve, double x) {
  if (curve == 1) return x * x;
  if (curve == 2) return std::sqrt(x);
  return x;
}
// Same contract as adsr: double accumulation — float increments stall past
// 2^25 samples and the envelope would freeze short of its target.
double env_increment(double seconds, double rate) {
  const double samples = std::max(seconds, 0.0) * rate;
  return samples <= 1.0 ? 1.0 : 1.0 / samples;
}
void env_gate(OpEnv& e, bool rising, bool falling) {
  using S = OpEnv::Stage;
  if (rising) {
    e.start = e.level;
    e.progress = 0.0;
    e.stage = S::S1;
  } else if (falling && e.stage != S::Idle && e.stage != S::Rel) {
    e.start = e.level;
    e.progress = 0.0;
    e.stage = S::Rel;
  }
}
bool env_segment(OpEnv& e, double target, double seconds, int curve,
                 double rate) {
  e.progress = std::min(1.0, e.progress + env_increment(seconds, rate));
  e.level = e.start + (target - e.start) * env_shape(curve, e.progress);
  if (e.progress < 1.0) return false;
  e.level = target;
  e.start = target;
  e.progress = 0.0;
  return true;
}
void env_tick(OpEnv& e, const EnvCfg& c, int curve, double rate) {
  using S = OpEnv::Stage;
  switch (e.stage) {
    case S::S1:
      if (env_segment(e, c.l[0], c.t[0], curve, rate)) e.stage = S::S2;
      break;
    case S::S2:
      if (env_segment(e, c.l[1], c.t[1], curve, rate)) e.stage = S::S3;
      break;
    case S::S3:
      if (env_segment(e, c.l[2], c.t[2], curve, rate)) e.stage = S::Hold;
      break;
    case S::Hold:
      e.level = c.l[2];
      break;
    case S::Rel:
      if (env_segment(e, 0.0, c.t[3], curve, rate)) {
        e.stage = S::Idle;
        e.level = 0.0;
      }
      break;
    case S::Idle:
      e.level = 0.0;
      break;
  }
}

class Fm final : public Module {
 public:
  void init(double rate, const Config& cfg) override {
    rate_ = rate;
    const std::string algo = cfg_str(cfg, "algo", "free");
    for (int i = 0; kAlgos[i]; ++i)
      if (algo == kAlgos[i]) algo_ = i;
    const std::string curve = cfg_str(cfg, "curve", "lin");
    for (int i = 0; kCurves[i]; ++i)
      if (curve == kCurves[i]) curve_ = i;
    sync_ = cfg_str(cfg, "sync", "on") != "off";

    fill(cfg, "ratios", ratios_, 1.0, 0.0, 1e9);
    const auto& levels = cfg_arr(cfg, "levels");
    for (int k = 0; k < kOps; ++k)
      levels_[k] = k < static_cast<int>(levels.size())
                       ? clampd(levels[static_cast<size_t>(k)], 0.0, 1.0)
                       : (k == 0 ? 1.0 : 0.0);
    fill(cfg, "fixed", fixed_, 0.0, 0.0, 1e9);
    fill(cfg, "fb", fb_, 0.0, 0.0, 0.999);
    fill(cfg, "vel_sens", vel_sens_, 0.0, 0.0, 1.0);

    static const double kTDef[4] = {0.002, 0.1, 0.4, 0.2};
    static const double kLDef[3] = {1.0, 0.75, 0.5};
    const char* tn[4] = {"t1", "t2", "t3", "t4"};
    const char* ln[3] = {"l1", "l2", "l3"};
    for (int k = 0; k < kOps; ++k) {
      for (int s = 0; s < 4; ++s) {
        const auto& a = cfg_arr(cfg, tn[s]);
        env_cfg_[k].t[static_cast<size_t>(s)] =
            k < static_cast<int>(a.size())
                ? std::max(0.0, a[static_cast<size_t>(k)])
                : kTDef[s];
      }
      for (int s = 0; s < 3; ++s) {
        const auto& a = cfg_arr(cfg, ln[s]);
        env_cfg_[k].l[static_cast<size_t>(s)] =
            k < static_cast<int>(a.size())
                ? clampd(a[static_cast<size_t>(k)], 0.0, 1.0)
                : kLDef[s];
      }
    }

    // Task 2 lands routing; every algorithm behaves as `free` until then.
    order_ = {0, 1, 2, 3, 4, 5};
    carrier_.fill(true);

    for (auto& e : envs_) e = OpEnv{};
    phase_.fill(0.0);
    prev_post_.fill(0.0f);
    prev_gate_ = 0.0f;
  }

  void process(const float* ins, float* outs) override {
    const float gate = ins[0];
    const bool high = gate > 0.5f;
    const bool rising = high && prev_gate_ <= 0.5f;
    const bool falling = !high && prev_gate_ > 0.5f;
    prev_gate_ = gate;
    if (rising && sync_) phase_.fill(0.0);
    for (auto& e : envs_) env_gate(e, rising, falling);

    const double base =
        static_cast<double>(clampn(ins[1], 0.0f, 0.45f * static_cast<float>(rate_))) *
        std::exp2(static_cast<double>(clampn(ins[2], -24.f, 24.f)));

    std::array<double, kOps> post{};
    for (int oi = 0; oi < kOps; ++oi) {
      const int k = order_[static_cast<size_t>(oi)];
      const double ratio = ratios_[static_cast<size_t>(k)];
      const double f = fixed_[static_cast<size_t>(k)] > 0.0
                           ? std::min(fixed_[static_cast<size_t>(k)], 0.45 * rate_)
                           : base * ratio;
      phase_[static_cast<size_t>(k)] += f / rate_;
      phase_[static_cast<size_t>(k)] -= std::floor(phase_[static_cast<size_t>(k)]);

      const double lvl = levels_[static_cast<size_t>(k)];
      env_tick(envs_[static_cast<size_t>(k)], env_cfg_[static_cast<size_t>(k)],
               curve_, rate_);
      const float s = std::sin(kTwoPi * static_cast<float>(phase_[static_cast<size_t>(k)]));
      post[static_cast<size_t>(k)] =
          envs_[static_cast<size_t>(k)].level * lvl * static_cast<double>(s);
      outs[1 + k] = static_cast<float>(post[static_cast<size_t>(k)]);
    }
    float out = 0.0f;
    for (int k = 0; k < kOps; ++k) {
      if (carrier_[static_cast<size_t>(k)])
        out += static_cast<float>(post[static_cast<size_t>(k)]);
      prev_post_[static_cast<size_t>(k)] = static_cast<float>(post[static_cast<size_t>(k)]);
    }
    outs[0] = out;
  }

  void copy_state_from(const Module& other) override {
    const auto& o = static_cast<const Fm&>(other);
    envs_ = o.envs_;
    phase_ = o.phase_;
    prev_post_ = o.prev_post_;
    prev_gate_ = o.prev_gate_;
  }

 private:
  static void fill(const Config& cfg, const char* name,
                   std::array<double, kOps>& dst, double def, double lo,
                   double hi) {
    const auto& a = cfg_arr(cfg, name);
    for (int k = 0; k < kOps; ++k)
      dst[static_cast<size_t>(k)] =
          k < static_cast<int>(a.size())
              ? clampd(a[static_cast<size_t>(k)], lo, hi)
              : def;
  }

  double rate_ = 48000.0;
  int algo_ = 0;
  int curve_ = 0;
  bool sync_ = true;
  std::array<double, kOps> ratios_{}, levels_{}, fixed_{}, fb_{}, vel_sens_{};
  std::array<EnvCfg, kOps> env_cfg_{};
  std::array<int, kOps> order_{};
  std::array<bool, kOps> carrier_{};
  // runtime state (migrated on hot reload)
  std::array<OpEnv, kOps> envs_{};
  std::array<double, kOps> phase_{};
  std::array<float, kOps> prev_post_{};
  float prev_gate_ = 0.0f;
};

std::unique_ptr<Module> make() { return std::make_unique<Fm>(); }
}  // namespace

const ModuleInfo fm_info{"fm", kIns, kCfg, kOuts, &make};
}  // namespace ms::dsp

namespace {
// One-sided DFT magnitude at an exact bin (coherent tones only).
double dft_mag(const std::vector<float>& x, double freq, double rate) {
  double re = 0.0, im = 0.0;
  for (size_t n = 0; n < x.size(); ++n) {
    const double a = 2.0 * M_PI * freq * static_cast<double>(n) / rate;
    re += x[n] * std::cos(a);
    im -= x[n] * std::sin(a);
  }
  return 2.0 / static_cast<double>(x.size()) * std::sqrt(re * re + im * im);
}

std::vector<Edge> parse_route(const std::vector<double>& route) {
  std::vector<Edge> edges;
  if (route.size() % 2 != 0) return {};
  for (size_t i = 0; i < route.size(); i += 2) {
    const double a = route[i], b = route[i + 1];

  void build_order() {
    std::array<int, kOps> indeg{};
    for (auto [s, d] : edges_) ++indeg[static_cast<size_t>(d)];
    std::array<bool, kOps> placed{};
    order_.fill(-1);
    for (int pos = 0; pos < kOps; ++pos) {
      int pick = -1;
      for (int k = 0; k < kOps; ++k)
        if (!placed[static_cast<size_t>(k)] && indeg[static_cast<size_t>(k)] == 0) {
          pick = k;
          break;
        }
      if (pick < 0) {  // cycle
        edges_.clear();
        for (int k = 0; k < kOps; ++k) order_[static_cast<size_t>(k)] = k;
        break;
      }
      order_[static_cast<size_t>(pos)] = pick;
      placed[static_cast<size_t>(pick)] = true;
      for (auto [s, d] : edges_)
        if (s == pick) --indeg[static_cast<size_t>(d)];
    }
    for (auto& p : preds_) p.clear();
    std::array<bool, kOps> has_out{};
    for (auto [s, d] : edges_) {
      preds_[static_cast<size_t>(d)].push_back(s);
      has_out[static_cast<size_t>(s)] = true;

```markdown
## `fm`

`fm { algo: dual, ratios: [...], levels: [...] }` — a 6-operator
phase-modulation voice (classic operator-FM family, locally designed; see
`docs/attribution.md`). Six sine operators with per-operator 4-segment
time/level envelopes; routing from a named algorithm set or a custom edge
list. Mono; polyphony via `voice` groups.

Inputs: `gate` 0 (rising fires all envelopes and, with `sync: on`, resets
phases; unpatched gate = silence), `freq` 440 Hz, `v_oct`, `vel` 1, per-op
`lvl1..lvl6` 0, `ratio1..ratio6` 0, `fb` 0 (adds to every op's feedback).
Outputs: `out` (straight sum of the carriers — gain-stage at the cable) and
post-envelope per-op taps `op1..op6` (pan/process carriers separately, or
tap a modulator to drive another module's FM input).

Routing: an edge a→b adds a's output to b's phase; ops with no outgoing
edge are carriers. Named algorithms: `free` (no edges — additive sine
stack), `triad` (2→1, 4→3, 6→5), `dual` (3→2→1, 6→5→4), `cascade`
(6→5→4→3→2→1), `crown` (2..6→1), `weave` (6,5→4→2, 3→2, 2→1). `algo:
custom` reads `route` as flat pairs — `route: [2,1, 3,2]` = 2→1, 3→2.
Pairs must be integral 1..6, no self-edges, no duplicates, acyclic; a
malformed route falls back to `free` (the session never dies).

Configs (all arrays are per-op, padded with the slot default, extras
ignored): `ratios` (all 1), `levels` (`[1,0,0,0,0,0]` — ops 2..6 stay off
until asked), `fixed` (per-op Hz; >0 pins the op off `v_oct`/`ratio` for
clicks and body resonances), `fb` (0..0.999; `fb[k] > 0` is itself the
self-edge — never put self-edges in `route`), `vel_sens` (0..1; op level ×=
(1−sens)+sens·vel), `t1..t4` segment seconds (0 = one-sample jump),
`l1..l3` segment levels, `curve` (`lin`/`exp`/`log`, default `lin` — `log`
is the natural percussive fall), `sync` (`on`/`off`, default `on`).
Envelope: gate rise runs 0→l1 over t1 → l2 over t2 → l3 over t3 and holds
l3; gate fall runs to 0 over t4, always from the current level. A level-1
modulator at envelope peak drives ±4π radians (index ≈ 12.6). `fm {}` bare
is a plain gated sine (op 1 only).
