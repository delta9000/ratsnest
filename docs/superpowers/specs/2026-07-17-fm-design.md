# FM design: `fm`

Date: 2026-07-17. Status: approved direction. A 6-operator phase-modulation
voice module — the ratsnest take on classic operator-FM synthesis, inspired by
the 1980s 6-operator instruments but designed from the published mathematics,
not from any Yamaha implementation. Concept-inspired after John M. Chowning,
"The Synthesis of Complex Audio Spectra by Means of Frequency Modulation,"
*JASA* 54(2), 1973; the technique's patent (US 4,018,121) expired in the
mid-1990s. See §7 for the full non-infringement analysis and provenance.

## 1. Goal and shape

FM is the largest synthesis-family gap in the palette: `vco.fm` gives linear
through-zero-ish two-oscillator FM, but multi-operator stacks with per-operator
envelopes and modulator feedback cannot be composed from cables (feedback
across modules costs one sample and self-oscillates differently; six cabled
oscillator/envelope pairs per voice is a patch maintenance failure). One module
captures the family, matching the `modal`/`string`/`grains` precedent for
self-contained voices.

`fm { algo: dual, ratios: [...], levels: [...] }` — mono signal path, 6 sine
operators, per-operator 4-segment time/level envelopes, routing from a named
algorithm set or a custom edge list. Polyphony comes from wrapping it in a
`voice` group, per project convention; nothing in the module knows polyphony
exists.

Not in scope: wavetable/non-sine operators, operator output waveforms other
than sine, a pitch envelope (cable `adsr`/`func` into `v_oct` — the patchable
inputs are the escape hatch for anything the configs can't express), per-op
panning (use the `op1..op6` taps into `mix`), DX-style keyboard level scaling
(deferred; velocity covers the expressive core).

## 2. Interface

| Input | Default | Range (clamped) | Meaning |
|---|---|---|---|
| `gate` | 0 | — | rising through 0.5 fires all 6 envelopes (and resets phases when `sync: on`); falling starts release from current level |
| `freq` | 220 | 0..0.45·rate | base frequency Hz (same convention as `vco`; `freq: 110hz` sets the base) |
| `v_oct` | 0 | — | octaves, exponentiates `freq` |
| `vel` | 1 | 0..1 | velocity; per-op `vel_sens` config decides how much it opens each op (sens default 0, so unpatched `vel` is inert — rule 4) |
| `lvl1..lvl6` | 0 | sum with base → 0..1 | add onto each op's base level — the live timbre knobs |
| `ratio1..ratio6` | 0 | sum with base → ≥0 | add onto each op's frequency ratio (slow morphs or audio-rate chaos) |
| `fbmod` | 0 | sum with base → 0..1 | adds to every op's feedback amount at once (named apart from the `fb` config array: the DSL resolves a `name:` param to an input port before a config of the same name, so the two must not collide — cf. `levels`/`lvl`, `ratios`/`ratio`) |

| Output | Meaning |
|---|---|
| `out` | straight sum of the **carrier** ops' post-envelope signals (no hidden normalization — gain-stage at the cable, `mix` precedent) |
| `op1..op6` | each op's post-envelope, post-level signal, carrier or modulator (separate processing, per-carrier panning, or tapping a modulator to drive another module's `fm`) |

| Config | Kind | Default | Meaning |
|---|---|---|---|
| `algo` | enum | `free` | `free`, `triad`, `dual`, `cascade`, `crown`, `weave`, `custom` |
| `route` | flat array | `[]` | edge pairs for `algo: custom`: `[2,1, 3,2]` = 2→1, 3→2 (a's output added to b's phase) |
| `ratios` | array ×6 | all 1 | per-op frequency ratio (multiplies `freq·2^v_oct`) |
| `levels` | array ×6 | `[1,0,0,0,0,0]` | per-op base level 0..1 (op 1 on, the rest off until asked — nothing implicit) |
| `fixed` | array ×6 | all 0 | per-op fixed frequency Hz; >0 pins the op (ignores `v_oct`, `ratio`, and `ratio` CV — attack clicks, body resonances) |
| `fb` | array ×6 | all 0 | per-op feedback amount 0..1 (sine → saw → noise only past ~0.9; see §3); **fb[k] > 0 *is* the self-edge declaration** (self-edges never appear in `route`) |
| `vel_sens` | array ×6 | all 0 | per-op velocity sensitivity 0..1: `level ×= (1−sens) + sens·vel` |
| `t1..t4` | array ×6 | `.002, .1, .4, .2` | envelope segment times, seconds (0 = one-sample jump) |
| `l1..l3` | array ×6 | `1, .75, .5` | envelope segment target levels 0..1 |
| `curve` | enum | `lin` | segment shape `lin`/`exp`/`log` (same math and names as `adsr`; `log` = fast-then-slow, the natural percussive fall) |
| `sync` | enum | `on` | `on` resets all op phases at the gate rising edge (repeatable attacks); `off` free-runs |

Array configs follow the `midi cc` convention: short arrays pad with the
slot's default, extra entries are ignored. With `gate` unpatched the envelopes
stay idle and the module is silent (same contract as `string`/`modal` without
excitation; `1 -> ep.gate` for a drone).

`fm {}` bare is a single plain sine (op 1, ratio 1, level 1, the neutral
default) — like `vco { wave: sine }` with a gate. Every modulation routing is
an explicit choice.

## 3. Routing

Six operators, numbered 1..6 in configs. An edge (a,b) means "a's post-
envelope output is summed into b's phase". An op with **no outgoing edge** is a
carrier (heard in `out`); anything else is a modulator. Multiple edges into
one op sum (that is the whole point of `crown`). Unreferenced ops are
carriers.

**Named algorithms** — our own topology set, designed from the generic FM
cookbook families (parallel carriers, carrier+modulator pairs, stacks,
converging trees), with our own names and numbering; not transcribed from any
instrument's algorithm table:

| `algo` | edges | carriers | character |
|---|---|---|---|
| `free` | — | 1,2,3,4,5,6 | additive sine stack |
| `triad` | 2→1, 4→3, 6→5 | 1,3,5 | three C+M pairs |
| `dual` | 3→2→1, 6→5→4 | 1,4 | two 3-op stacks (EP/bell layering) |
| `cascade` | 6→5→4→3→2→1 | 1 | one deep stack (extreme brightness) |
| `crown` | 2,3,4,5,6 →1 | 1 | five modulators on one carrier |
| `weave` | 6→4, 5→4, 4→2, 3→2, 2→1 | 1 | asymmetric converging tree |

**Custom**: `algo: custom` reads `route` as flat (from,to) pairs. Graph
validation rejects malformed routes: pairs must be integral 1..6, from≠to,
without duplicates, and acyclic. `check` reports the error; live reload retains
the last good graph. Direct module initialization retains a defensive fallback
to `free`, but compiled patches cannot reach it.

**Evaluation order** is topological (modulators before their targets),
computed once at `init()` by Kahn's algorithm, so every feed-forward edge is
same-sample. A feedback self-edge (from the `fb` array) reads the **average of the op's
own previous two** enveloped outputs, so it needs no special ordering. The
phase offset is `2.5 · fb · (y[n−1] + y[n−2]) / 2` rad, where `y` is the op's
waveform × envelope *before* its level/`lvl`/`vel`/key-level scaling: `fb`
names one timbre on any op, quiet modulator or loud carrier. The two-sample
average is Tomisawa's anti-hunting fix for feedback FM (US 4,249,447, 1981;
see `docs/attribution.md`): a lone previous sample oscillates sign-for-sign
at Nyquist once the feedback index passes ~1.2 rad and the op collapses to
noise; averaged, a 220 Hz op stays harmonic (sine → ~1/n saw) to ~2 rad and
breaks only past ~2.25 rad. 2.5 rad full scale therefore spends fb 0..0.8 on
sine → brightest saw and leaves only the top ~10% to noise. `fb` 0 skips the
term entirely, sample-identical to an op without feedback.

## 4. Envelope

Each op has a 4-segment time/level envelope, the shape FM repertoire needs
(strike-decay-tail mallets and EPs, percussive partials):

```
gate rises:  0 (or current level) --t1--> l1 --t2--> l2 --t3--> l3 --[hold while gate high]
gate falls:  current level --t4--> 0
```

- Times in seconds, 0 = one-sample jump (same `increment()` convention as
  `adsr`, double accumulation so long tails never stall).
- Retrigger and release both start from the **current** level (the `adsr`
  retrigger contract), so legato re-strikes never click.
- `curve` applies the `adsr` shapes per segment: `lin` x, `exp` x² (slow
  start), `log` √x (fast start — natural bell/EP decay).
- All six envelopes share the module's gate; per-op rhythm tricks come from
  differing t/l arrays, not per-op gates.

## 5. DSP core

Per sample, per op k (in topo order):

```
base  = clamp(freq, 0, .45·rate) · 2^v_oct            # NaN-proof clamps
f_k   = fixed_k > 0 ? clamp(fixed_k, 0, .45·rate)
      : base · max(ratios_k + ratioCV_k, 0)           # ratio 0 = frozen op
L_k   = clamp(levels_k + lvlCV_k, 0, 1) · ((1−sens_k) + sens_k·clamp(vel,0,1))
mod_k = Σ_{j→k} post_j                                # bounded: |mod| ≤ ~6
fbφ_k = 2.5 · clamp(fb_k + fbCV, 0, 1) · (y_k[n−1] + y_k[n−2]) / 2   # §3
phase_k += f_k / rate  (double, wrap; reset on gate rise when sync on)
s_k   = sin(2π·phase_k + kIndex · mod_k + fbφ_k)    # fbφ term absent at fb 0
y_k   = env_k · s_k                                   # feedback tap (pre-level)
post_k = env_k · L_k · s_k                            # → op<k+1> tap
out   = Σ post over carriers
```

`kIndex = 4π`: a level-1 modulator at envelope peak drives ±4π rad of phase
(modulation index ≈ 12.6), comparable to the classic instruments' maximum
operator output. Levels clamp to 0..1, so index stays musical; push a
modulator's `lvl` for the bright end.

Aliasing: high-index FM at high pitches aliases; that is intrinsic to the
technique and part of the classic sound. No anti-aliasing (the carriers are
exact sines; there is nothing to pre-bandlimit).

## 6. Runtime integration & robustness

- **Rule 3**: allocation only in `init()` (edge vectors, topo order);
  `process()`/`copy_state_from()` use fixed `std::array` state. No I/O, no
  locks.
- **Hot reload** (`copy_state_from`): copy all op phases, every envelope's
  stage/level/start/progress, `prev_gate`, and the two feedback taps. Config edits
  (ratios, route, …) build a fresh instance whose state carries, so an
  algorithm swap mid-note bends rather than restarts.
- **Denormals**: no IIRs and no accumulating feedback (feedback reads a fresh
  bounded sine product each sample), so there is no decaying recursive state
  to flush. Envelope Idle pins level to exact 0.
- **Hostile inputs** (rule 6): NaN-proof `!(x >= lo)` clamps on `freq`,
  `v_oct`, `vel`, `lvl`, `ratio`, `fb`; `gate` NaN reads low. Every quantity
  is bounded, so no patch can blow the module up; the engine's NaN guard is
  the backstop.
- **Signal conventions** (rule 8): gate rises through 0.5; `vel` unipolar;
  `v_oct` octaves; `out`/taps are bipolar audio (multi-carrier sums can
  exceed ±1 — gain-stage at the cable, `mix` precedent).

## 7. Provenance & non-infringement

The module implements the published phase-modulation formula
`y = A·sin(2πf_c·t + I·sin 2πf_m·t)` (mathematically equivalent to Chowning's
frequency modulation; standard literature, e.g. Roads, *The Computer Music
Tutorial*). What makes this module merely *inspired by* the classic 6-op
instrument rather than a clone:

- **Not used**: the 32 factory algorithm layouts or their numbering; the
  rate/level parameter tables and scaling curves; ROM/sysex data; factory
  voice names; panel/UI conventions; any Yamaha trademarks in code or
  user-facing names.
- **Original here**: the algorithm set (§3) and its names; routing as
  patch-file data (`route` edge lists — a thing no 1983 instrument could
  express); seconds+levels envelopes (not Yamaha's rate units); the additive
  ratsnest input-summing model; per-op taps.

The implementation is written locally from the published math; no existing
FM implementations were consulted or copied.

Self-feedback with a two-sample average follows Norio Tomisawa's published
feedback-FM patent (US 4,249,447, filed 1979, granted 1981, expired), whose
"averaging device" adds adjacent output samples and halves them to stop
hunting; implemented here from that description, the full-scale constant and
pre-level tap are this module's own.

Attribution work in the same diff (CLAUDE.md rules): a **concept-inspired**
row in `docs/attribution.md` citing Chowning 1973 and Tomisawa 1981 and noting
the expired patents, and a comment at the top of `fm.cpp` pointing to it. No code is
copied, so `THIRD_PARTY_NOTICES.md` is unchanged. The `test_docs.cpp`
attribution checks keep passing (it asserts presence, not exclusivity).

## 9. Testing (doctest, per file)

- Registry/docs coverage (existing `test_docs.cpp` enforces the `## fm`
  heading).
- Envelope (at 1 kHz rate, op carrier trick `freq = rate/4` so every 4th
  sample reads the envelope directly): segment times and levels exact; l3
  hold; release from current level; retrigger from current level; zero-time
  segments jump in one sample; `curve` shapes.
- `free`: six-sine sum (levels default → op1 only); `out` == sum of carrier
  taps.
- 2-op FM correctness: known index (level-0.25 modulator → I = π), coherent
  DFT sidebands match `std::cyl_bessel_j(n, π)` magnitudes.
- Routing: carrier inference; malformed `route` (odd count, out of range,
  self-edge, duplicate, cycle) is rejected by graph validation; direct module
  initialization defensively falls back to `free` sample-identically.
- Named algorithms: each is sample-identical to its `custom` expansion.
- Feedback: raises spectral centroid; at fb 0.3/0.6/0.8 a held carrier's
  off-harmonic energy stays below −60/−60/−35 dB with h2, h3, h5 ≳ 1/n; fb 1
  breaks into noise; bounded and finite at fb 1 under hostile `fbmod`; fb 0 is
  bit-identical to the no-feedback arithmetic; timbre is independent of op level.
- Live surface: `vel`/`vel_sens`, `lvl`, `ratio`, `fb` inputs sum onto bases;
  `fixed` op ignores `v_oct`; `sync: off` free-runs (retriggered attacks
  differ; `on` reproduces them exactly).
- Hot reload: `copy_state_from` continues sample-identically.
- Hostile inputs: NaN on every control input → finite output.
- Integration: a `voice`-group `fm` patch parses, compiles, and renders
  non-silent and bounded through `engine::Engine`.
- `mise run test`, `mise run test-san`, `mise run ci` all pass.
