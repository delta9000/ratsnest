# Euclidean Rhythm Generator Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Add a real-time Euclidean rhythm module with trigger and gate outputs.

**Architecture:** Detect clock/reset rising edges, evaluate a constant-time bucket formula for each step, and preserve the selected hit for the incoming clock's high phase. Clamp and wrap live parameters defensively; migrate all scalar runtime state.

**Tech Stack:** C++20, doctest, ratsnest patch DSL, CMake/mise

### Task 2: Implement and register `euclid`

**Files:**
- Create: `src/dsp/modules/euclid.cpp`
- Modify: `src/dsp/modules.h`
- Modify: `src/dsp/registry.cpp`
- Modify: `docs/superpowers/specs/2026-07-10-ratsnest-design.md`

1. Define inputs `clock`(0), `reset`(0), `steps`(16), `hits`(4), `rot`(0), and
   outputs `trig`, `gate`.
2. On reset edge set step to -1 and clear the active hit. On clock rise, advance
   to `(step + 1) % steps`, then compute
   `((step + wrapped_rotation) * hits) % steps < hits`.
3. Output `trig` only on a rising clock hit; output `gate` while clock is high
   and the current step is a hit. Copy step, active hit, and prior edge levels
   in `copy_state_from`.
4. Append `euclid_info` last in header and registry order; expand the spec row
   with exact ports, ranges, and semantics.
5. Run the focused tests and confirm all pass.
